## 5 阶段一览

| # | 阶段 | 子标签 | 产出 |
|---|------|--------|------|
| 1 | 素材输入 | 视频提取 / 文字输入 / 文件提取 | 原始文本内容 |
| 2 | 文档生成 | 标准文档 / 分析文档 / 综合文档 | 3 份 AI 生成文档（Markdown） |
| 3 | 课件输出 | 文档课件 / 分析PPT / 综合PPT | HTML/SVG 幻灯片（可在线预览编辑） |
| 4 | 演讲课件 | 演讲文案 / 演讲口播 | 口播稿 + .mp3 音频 |
| 5 | 输出列表 | (无) | 一键下载 .zip |

### 数据流向

- Stage 1 输出文本 → Stage 2 三路并发生成文档
- Stage 2 三路文档 → Stage 3 对应三路课件（HTML/SVG）
- Stage 2 综合文档 → Stage 4 演讲文案 → 演讲口播（.mp3）
- Stage 3 + Stage 4 所有产出 → Stage 5 汇总下载（.zip）
