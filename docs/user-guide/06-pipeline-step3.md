# 06 — Stage 3：课件输出

## 功能位置
项目详情页 → **「Stage 3 · 课件输出」**

## 前置条件
- Stage 2 已完成（至少一份文档生成）
- 已在「模板管理」中启用至少一个 VI 设计风格
- LLM 配置正常

## 操作说明

### 三个子标签

Stage 3 将 Stage 2 的三份文档分别转化为课件：

| 子标签 | 课件类型 | 对应文档 |
|--------|---------|---------|
| **文档课件** | SOP 标准课件 | Stage 2 标准文档 |
| **分析PPT** | 道与术分析课件 | Stage 2 分析文档 |
| **综合PPT** | 研学手册课件 | Stage 2 综合文档 |

### 生成课件（每个子标签独立操作）

1. 切换到目标子标签
2. 在左侧 **「选择模板」** 区域选择：
   - **VI 设计风格**（从模板管理中已启用的风格中选择）
   - **配色方案**（风格内置色系）
3. 选择 **LLM 模型**（可调整温度参数）
4. 点击 **「生成 PPT」**
5. 生成完成后可在线预览幻灯片，支持：
   - 逐页浏览
   - 单页编辑（自然语言指令 → AI 修改）
   - 配色切换
   - 单页重生成
6. 点击 **「下载」** 导出 HTML 课件或 SVG 文件包

### PPT 导出格式

| 格式 | 说明 |
|------|------|
| HTML 课件 | 可直接在浏览器中打开播放的交互式幻灯片 |
| SVG 文件包 | 多页 SVG 文件打包为 .zip，可用矢量编辑软件打开 |

## 预期结果
- 课件生成完成后可在预览区逐页查看
- 可在线编辑和切换配色
- 下载 HTML/SVG 文件可正常打开

## 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 课件生成失败 | LLM 返回格式异常 | 重试或更换模型 |
| 没有可选模板 | 所有风格被禁用 | 前往「模板管理」启用至少一个风格 |
| 生成效果与预期不符 | VI 规范与内容不匹配 | 编辑对应风格的「设计指导思想」或「提示词」 |
| 下载文件为空 | 生成未完成 | 等待生成完成后再下载 |
