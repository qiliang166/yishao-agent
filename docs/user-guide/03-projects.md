# 03 — 项目管理

## 功能位置
首页（项目列表页），侧边栏「项目管理」

## 前置条件
- 应用已启动

## 操作说明

### 新建项目
1. 点击右上角 **「+ 新建项目」** 按钮
2. 在弹出的对话框中填写：
   - **项目名称**（必填）
   - **项目图标**（可选，支持 emoji、URL 或本地上传）
   - **项目简介**（可选）
   - **复制配置自**（可选，选择已有项目将其提示词、演讲、语音等配置复制到新项目）
   - **可见角色**（可选，勾选后该角色下所有会员自动可见此项目）
   - **状态**：草稿 / 已完成
3. 点击「创建」
4. 新项目出现在列表中，自动跳转到项目详情页

### 查看项目列表
首页自动加载所有项目。每个项目卡片显示：
- 项目图标（自定义图片或默认 📁）
- 项目名称
- 状态标签（草稿 / 已完成）
- 操作按钮（进入 / 删除）

列表底部显示项目总数，每页显示 16 条，超过时自动分页。

### 删除项目
- 点击项目卡片上的「删除」按钮，确认后删除
- 仅项目创建者或拥有 `project.delete_own` 权限的用户可删除
- 删除项目会同时清理项目存储目录中的文件

### 搜索项目
顶部搜索框输入关键词，按名称过滤项目。

## 预期结果
- 新建后：列表中出现新卡片，自动跳转到项目详情
- 删除后：卡片从列表消失，存储目录同时清理
- 搜索：输入关键词即时过滤列表

## 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 新建后列表不刷新 | 网络延迟 | 手动刷新页面 (F5) |
| 删除失败弹窗 | API 请求失败或无权限 | 检查后端是否正常运行，确认有删除权限 |
