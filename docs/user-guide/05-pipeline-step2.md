# 05 — Stage 2：文档生成

## 功能位置
项目详情页 → **「Stage 2 · 文档生成」**

## 前置条件
- Stage 1 已完成（已有素材内容）
- 已配置至少一个 LLM 提供商

## 操作说明

### 三个子标签

Stage 2 以三个子标签并排显示，每个标签对应一份独立文档：

| 子标签 | 文档类型 | 说明 |
|--------|---------|------|
| **标准文档** | SOP 标准操作流程 | 结构化的操作规范文档 |
| **分析文档** | 道与术分析 | 原理分析与技巧总结 |
| **综合文档** | 研学手册 | 综合性的学习指南 |

### 操作步骤（每个子标签独立操作）

1. 切换到目标子标签（标准文档 / 分析文档 / 综合文档）
2. 选择该文档类型的 **提示词版本**
3. 选择 **LLM 模型**
4. 点击 **「生成」** 按钮
5. AI 根据 Stage 1 的素材内容和提示词生成文档
6. 生成后可在编辑器中手动修改或使用 AI 协助（润色 / 扩写 / 精简）

### AI 协助操作

| 操作 | 步骤 |
|------|------|
| **润色选中** | 选中文字 → 点击「润色选中」→ AI 仅改写选中部分 |
| **扩写** | 选中文字 → 点击「扩写」→ AI 将选中部分扩展 |
| **精简** | 选中文字 → 点击「精简」→ AI 将选中部分压缩 |
| **自定义指令** | 选中文字（可选）→ 输入指令（如「改成更正式的语调」）→ 执行 |

### 并发生成
- 三份文档可同时生成，互不影响
- 每个文档独立选择提示词和模型
- 可分别为三份文档选择不同的 LLM 提供商

## 预期结果
- 每份文档独立生成后显示在对应子标签的编辑区
- 生成后可编辑修改
- 三份全部确认 → 可进入 Stage 3

## 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 生成失败 | LLM 配置错误或余额不足 | 检查全局配置中的 LLM 设置 |
| 生成内容为空 | 提示词 + 模型组合不匹配 | 尝试更换模型或提示词 |
| 三份文档内容重复 | 提示词未区分文档类型 | 确认每个子标签使用了对应分类的提示词 |
| 生成超时 | 模型响应慢或内容过长 | 缩短 Stage 1 的内容或更换更快的模型 |
