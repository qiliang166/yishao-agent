# 04 — Stage 1：素材输入

## 功能位置
项目详情页 → **「Stage 1 · 素材输入」**

## 前置条件
- 已创建项目
- 已进入项目详情页

## 操作说明

### 三个子标签

Stage 1 提供三种素材输入方式：

| 子标签 | 说明 |
|--------|------|
| **视频提取** | 粘贴视频链接，下载后自动提取字幕/语音转写 |
| **文字输入** | 直接粘贴或输入文本内容 |
| **文件提取** | 上传 .txt / .md / .docx 文件 |

### 视频提取
1. 将视频链接（如抖音、B站、YouTube 链接）粘贴到输入框
2. 选择 ASR 提供商和模型（需在「全局配置 → 模型设置」中预先配置）
3. 点击 **「开始下载」**
4. 等待下载完成，系统自动进行字幕提取 + ASR 语音识别，LLM 交叉验证生成合并文本
5. 文本区上方出现来源切换标签：**合并版** | **语音识别** | **字幕**
6. 可手动编辑文本

#### 来源切换标签
视频下载完成后，文本区上方显示三个标签：

| 标签 | 说明 |
|------|------|
| 合并版 | LLM 交叉验证合并字幕和语音识别结果（默认），差异处标注来源 |
| 语音识别 | 纯 ASR 语音转写结果 |
| 字幕 | 视频内嵌字幕原文（可能为空） |

#### 视频播放校验
点击 **「播放校验」** 按钮打开校验窗口，左侧播放视频，右侧对照文本内容。

### 文字输入
1. 在编辑区直接粘贴或输入文本
2. 点击 **「保存」** 持久化内容（刷新不丢失）

### 文件提取
1. 选择 `.txt` / `.md` / `.docx` 文件
2. 文件内容自动加载到编辑区
3. 可继续手动编辑

### 进度状态

| 状态 | 说明 |
|------|------|
| 🔄 下载中 | 正在下载视频，进度条显示百分比 |
| 📝 语音识别中 | 正在 ASR 语音转写 |
| 🔀 交叉验证中 | LLM 合并字幕和语音识别结果 |
| ✅ 完成 | 下载完成，文本已提取 |
| ❌ 失败 | 下载或提取失败 |

## 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| 下载失败 | 链接无效或平台不支持 | 检查链接格式，确认平台在支持列表内 |
| 字幕为空 | 视频无内嵌字幕 | 查看「语音识别」标签获取 ASR 结果 |
| ASR 转写失败 | ASR 提供商未配置或余额不足 | 检查「全局配置 → 模型设置」中的 ASR 提供商 |
| yt-dlp 报错 | 缺少 VC++ 运行时 | 安装 Microsoft Visual C++ Redistributable |
