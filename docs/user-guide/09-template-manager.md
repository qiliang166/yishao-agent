# 09 — 模板管理（VI 风格管理器）

## 功能位置
左侧导航 → **「模板管理」**

## 概述

模板管理页面用于管理 **VI（视觉识别）设计风格**。Stage 3（输出课件）生成 PPT 时，会根据所选风格的配色、字体、排版规则来生成幻灯片。

## 页面布局

页面顶部有 4 个风格分组标签：

| 分组 | 说明 |
|------|------|
| **商务专业** | 干净、权威、可信赖 |
| **创意大胆** | 活力、鲜艳、表现力强 |
| **科技暗色** | 前卫、精确、未来感 |
| **主题风格** | 教育、奇幻、经典复古 |

每个风格以卡片形式展示：名称、风格描述（mood）、主色/强调色/背景色/文字色色块。

## 操作说明

### 查看和编辑风格

1. 点击风格卡片的名称展开详情
2. 点击 **「编辑VI」** 打开 VI 编辑器
3. VI 编辑器中包含以下可编辑章节：

| 类别 | 章节 | 说明 |
|------|------|------|
| 总纲 | 通用规范 (I01) | 整体设计原则和约束 |
| | 提示词 (I02) | 生成提示词模板 |
| | 配色令牌 (I03) | 色彩方案定义（可添加/编辑色系） |
| 设计原则 | 设计指导思想 (D01) | 布局与视觉层次规则 |
| | 跨页一致性 (D02) | 跨页面统一的元素规则 |
| | 视觉丰富度 (D03) | 装饰元素使用规范 |
| | 自检清单 (D04) | 生成后质量检查项 |
| | 配图规范 (D05) | 图片使用规则 |
| | 数据转化规则 (D06) | 数据可视化规范 |
| | 装饰系统 (D07) | 装饰元素库 |
| 设计元素 | 色彩系统 (E01) | 完整配色体系 |
| | 排版层级 (E02) | 字体、字号、行高规范 |
| | 卡片样式 (E03) | 内容卡片设计规则 |
| | 图表语言 (E04) | 图表设计语言 |
| | 布局库 (E05) | 页面布局模板 |
| | 卡片角色 (E06) | 卡片功能分类 |
| | 图表决策树 (E07) | 图表选择逻辑 |
| | 图标规范 (E08) | 图标使用标准 |
| 构建块 | 页头/标题/信息块等 (B01-B08) | 页面构建块设计规范 |
| 页面类型 | P01-P27 | 各页面类型的设计规范（封面、内容页、数据页等） |

### 管理色系

1. 展开风格卡片 → 点击 **「编辑VI」** → 切换到 **「配色令牌 (I03)」** 标签
2. 可查看和编辑各色系的主色、强调色、背景色、文字色
3. 点击 **「+ 新增色系」** 添加自定义色系
4. 色系在 Stage 3 生成课件时可选

### 启用 / 禁用风格

- 展开风格卡片 → 切换 **「在模板选择中显示」** 开关
- 关闭后该风格不会出现在 Stage 3 的模板选择器中

## 与课件生成的关系

在 Stage 3（输出课件）中：
1. 左侧 **「选择模板」** 区域显示所有已启用的设计风格
2. 选择一个风格后，系统根据该风格的 VI 规范生成幻灯片
3. 可在色系下拉框中选择不同的配色方案

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Stage 3 中没有风格可选 | 所有风格都被禁用 | 在模板管理中启用至少一个风格 |
| 生成效果与预期不符 | VI 规范与内容不匹配 | 编辑对应风格的「设计指导思想」或「提示词」 |
| 配色不符合需求 | 默认色系不合适 | 在「配色令牌」中添加或编辑色系 |
