# 02 — 快速上手

## 启动应用

双击 `start.bat`（Mac/Linux 运行 `start.sh`），等待 5-10 秒，浏览器自动打开 `http://localhost:5173`。

## 首次使用：跟随向导（推荐）

首次启动后会自动弹出 **「快速上手」向导**，7 个步骤带你完成第一个项目：

```
1 环境检查 → 2 创建项目 → 3 整理素材 → 4 生成文档 → 5 生成课件 → 6 演讲配音 → 7 完成
```

> 每个步骤标题都可以**直接点击**跳转，不需要逐页翻。

### 第 1 步：环境检查

向导会自动检查 4 项配置：

| 检查项 | 说明 | 未配置时怎么办 |
|--------|------|----------------|
| LLM 提供商 | AI 生成的核心引擎，**必须配置** | 点击「去配置」添加 API Key |
| PPT 模板 | VI 设计风格，决定课件外观 | 点击「去模板管理」启用风格（系统内置 18 套） |
| TTS 提供商 | 语音合成引擎 | 点击「去配置」添加 TTS 服务 |
| 种子提示词 | 系统预设的提示词配置 | 首次使用需在项目设置中初始化 |

LLM 提供商是必须的，其他可在后续补配置。

### 第 2 步：创建项目

输入项目名称，点击「创建项目」。系统会自动创建项目并关联默认的提示词配置。

### 第 3 步：整理素材

输入或粘贴文本内容（食谱步骤、教学材料等），点击 **「开始整理素材」**。AI 将原始内容整理为结构化文档。

内置了一段示例文本，可直接点击生成体验流程。

### 第 4 步：生成文档

AI 基于上一步的素材生成教学文档。如果跳过上一步，也会使用内置示例。

### 第 5 步：生成课件

选择 VI 设计风格（决定幻灯片的配色和排版），AI 将文档内容转化为 HTML 幻灯片。生成后可在预览窗口浏览和编辑。

### 第 6 步：演讲配音

输入或生成口播稿 → 选择 TTS 语音 → 点击「语音合成」生成 .mp3 音频。

### 第 7 步：完成

查看本次生成的所有产物，点击「前往项目」进入完整的项目工作台。

---

## 向导 vs 完整流水线

快速上手向导是一个**自动化简化流程**，适合体验和快速产出。日常使用建议直接进入项目详情页，使用完整的 **5 阶段流水线**：

| 阶段 | 名称 | 做什么 |
|------|------|--------|
| 1 | 文案提取 | 视频/文字/文件 → 结构化素材 |
| 2 | 教学文档 | AI 并发生成 3 份文档（SOP · 道与术 · 研学手册） |
| 3 | 输出课件 | 文档 → HTML/SVG 课件（可逐页预览编辑） |
| 4 | 语音课件 | 研学手册 → 口播稿 → TTS 语音合成 .mp3 |
| 5 | 输出列表 | 所有产出文件一览，支持批量下载 .zip |

- [ ] 启动应用（`start.bat`）

- [ ] 完成快速上手向导，体验完整流程
- [ ] 进入项目详情页，探索 5 阶段流水线的各个功能
