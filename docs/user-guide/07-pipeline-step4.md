# 07 — Stage 4：演讲课件

## 功能位置
项目详情页 → **「Stage 4 · 演讲课件」**

## 前置条件
- Stage 2 已完成（至少一份文档生成，通常使用综合文档/研学手册）
- 已配置 TTS 提供商（在「全局配置 → 模型设置」中）

## 操作说明

### 两个子标签

| 子标签 | 说明 |
|--------|------|
| **演讲文案** | AI 根据文档生成适合朗读的口播稿 |
| **演讲口播** | TTS 语音合成，将口播稿转为 .mp3 音频 |

### 生成演讲文案
1. 切换到 **「演讲文案」** 子标签
2. 选择 **LLM 模型**
3. 点击 **「生成演讲稿」** 或 **「从文档生成」**
4. AI 根据 Stage 2 的文档内容生成口语化演讲稿（含开场白、停顿、重点强调标注）
5. 手动编辑演讲稿（调整语气、断句、时长等）

### TTS 语音合成
1. 切换到 **「演讲口播」** 子标签
2. 确认演讲稿内容已准备好
3. 选择 **TTS 提供商和模型**（如 cosyvoice-v3-flash）
4. 点击 **「语音合成」**
5. 等待 TTS 处理（长文本自动分段合成）
6. 合成完成后：
   - 点击播放按钮 **试听**
   - 点击 **「下载音频」** 保存 .mp3 文件

### SOP 导出（可选）
- 在 SOP 导出区域输入或粘贴内容（通常来自标准文档）
- 选择 **SOP 模版**（可选）
- 填写品牌信息（版权文字、签名位置）
- 点击 **「导出 SOP」** → 下载 .docx 文件

## 预期结果
- 演讲文案 → AI 生成口语化文本，可编辑
- TTS 合成 → 可播放和下载 .mp3 音频
- SOP 导出 → 下载 .docx 文件可正常打开

## 常见错误

| 问题 | 原因 | 解决 |
|------|------|------|
| TTS 合成失败 | TTS 服务未配置或余额不足 | 检查「全局配置 → 模型设置」中的 TTS 提供商 |
| 音频无声 | TTS 合成参数问题 | 调整音量（volume）参数 |
| SOP 导出失败 | python-docx 写入错误 | 检查内容格式，避免特殊字符 |
