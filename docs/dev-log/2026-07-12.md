# 2026-07-12: RBAC + 会员系统 — 端到端验证 + paid审批修复

## 修复

### paid 会员审批天数 bug
`PUT /api/members/{id}/approve` 对已付费会员错误使用 body 中的 `duration_days`（默认 7），而非 payment_records 中记录的 `duration_days`（90）。

**根因**: 付费分支 line 6365 未读取 `payment["duration_days"]`。

**修复**: [app.py:6361-6365](backend/app.py#L6361-L6365) — `role_name = "付费会员"` 分支新增 `duration_days = payment["duration_days"]`。
