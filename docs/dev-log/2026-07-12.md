## 修复

### paid 会员审批天数 bug
`PUT /api/members/{id}/approve` 对已付费会员错误使用 body 中的 `duration_days`（默认 7），而非 payment_records 中记录的 `duration_days`（90）。

**根因**: 付费分支 line 6365 未读取 `payment["duration_days"]`。

**修复**: [app.py:6376](backend/app.py#L6376) — `role_name = "付费会员"` 分支新增 `duration_days = payment["duration_days"]`。

### 客户端篡改金额/天数风险
客户端可提交任意 `amount_cents` 和 `duration_days`，无服务端校验。

**修复**: 新增服务端 PLANS 字典（app.py:36-40），客户端仅传 `plan_id`，价格/天数由服务端权威决定。前端 [MemberRegisterPage.tsx:74](frontend/src/pages/MemberRegisterPage.tsx#L74) 改为发送 `plan_id: 'quarterly'`。

### email UNIQUE 约束导致空邮箱注册失败
`email TEXT UNIQUE` 约束下，多个用户不填邮箱时均插入空字符串 `""`，触发 `UNIQUE constraint failed: users.email`。

**修复**: 
- [app.py:6221](backend/app.py#L6221) — `email = ... or None`，空字符串转为 NULL
- [routers/users.py:268](backend/routers/users.py#L268) — 同上

- 注册端点每 IP 每小时 3 次
- 429 响应含 Retry-After 提示

## 关键安全设计
- 防用户枚举: 所有登录失败返回 403（非 401），统一错误消息"用户名或密码错误"
- 防客户端篡改: PLANS 字典服务端权威定价
- 密码哈希不泄露: `/api/users/:id` 和 `/api/auth/me` 均不含 password_hash
- 系统角色保护: is_system=1 的角色不可删除/修改权限
- 超级管理员保护: 不可删除/停用
- token 版本控制: 权限变更时 token_version++，强制重新登录（已验证）
- 跨用户隔离: 会员仅见已分配 workspace 的项目，直接 URL 访问被拒（已验证）
- 账号锁定: 10 次失败锁定 30 分钟，正确密码不受影响（已验证）
- 会员写入保护: 所有 POST/PUT/DELETE 端点拒绝会员请求（已验证）

### 修复

#### 1. 点击"项目管理"白屏 → 无限渲染循环
**根因**: 外层 `<Routes>` 将 `/` 匹配到 `LandingPage`，已登录 admin 被重定向到 `/home`，但 `AppShell` 内无 `/home` 路由。同时 `LandingPage` 的 `useEffect` 重定向 + 组件挂载/卸载周期触发 "Maximum update depth exceeded"。

**修复**:
- [App.tsx](/frontend/src/App.tsx) — 新增 `RootRoute` 组件，先检查 auth 状态再决定渲染 `LandingPage` 还是重定向，避免已登录用户挂载 `LandingPage`
- [App.tsx](/frontend/src/App.tsx) — `AppShell` 内新增 `<Route path="/home" element={<HomePage />} />`

#### 2. `update_user` 空邮箱触发 UNIQUE 约束
**根因**: 管理员编辑用户时不填邮箱，前端发送 `email: ""`，后端直接写入空字符串，与已有空字符串邮箱冲突。

**修复**: [routers/users.py:319](backend/routers/users.py#L319) — `email_val = req["email"].strip() if req["email"] else None`

#### 3. 付费会员审批天数被套餐默认值覆盖
**根因**: 双重覆盖 —
- 前端 [MemberApprovalPage.tsx:71](frontend/src/pages/MemberApprovalPage.tsx#L71): 付费会员直接取 `m.payment.duration_days` (套餐默认90天)，忽略管理员输入
- 后端 [app.py:6378](backend/app.py#L6378): 付费分支强制覆盖 `duration_days = payment["duration_days"]`

**修复**: 前端移除 `m?.payment ? (m.payment.duration_days || 90) : durationDays` 逻辑，直接使用管理员输入的 `durationDays`；后端移除付费分支的覆盖行。

#### 4. `sqlite3.Row.get()` 不存在
**根因**: `list_users` 中新增 `phone` 字段时使用 `r.get("phone", "")`，但 `sqlite3.Row` 无 `.get()` 方法。

**修复**: [routers/users.py:223](backend/routers/users.py#L223) — 改为 `dict(r).get("phone", "")`
