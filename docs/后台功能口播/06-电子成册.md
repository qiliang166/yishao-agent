# 电子成册

## ① 一句话定位
电子成册，是把已经做好的内容，打包成一本可以翻页、可以下载的电子书的地方。

## ② 使用场景
当你手里有一批已经生成好的内容，想把它们组装成一本书发给别人，就用电子成册。

## ③ 分步操作
第一步，点「新建册子」。
第二步，填「书名」，再选「册子类型」，有「A4 书册版」和「PPT 合辑版」两种，选完点「创建并编辑」。
第三步，进入编辑器后，按步骤往下走：「选内容」「排序与编辑」「封面署名」「页面编排」「预览合成」。
第四步，最后在预览页确认没问题，就能下载了。
如果你要一次做好几本，就点「批量新建」，勾选多个项目，填好封面信息，点「开始批量合成」。

## ④ 预期结果
合成完成后，会提示「已打包 N 本电子书」，你就能下载一个压缩包，里面就是做好的书。

## ⑤ 避坑提醒
注意，「册子类型」一旦创建就改不了了，选的时候要想清楚。另外，编辑过程中记得点「保存草稿」，不然刷新会丢。
