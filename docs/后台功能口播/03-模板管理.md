# 模板管理

## ① 一句话定位
模板管理，是存放各种"视觉风格"的地方。每个模板，决定了生成出来的课件和文档长什么样。

## ② 使用场景
当你觉得现在生成的东西不好看，想换一种配色、换一种版式，就来模板管理挑一个。

## ③ 分步操作
第一步，看顶部的分组标签，有「商务专业」「创意大胆」「科技暗色」「主题风格」四种，点其中一个。
第二步，在出现的模板卡片上，点「预览VI」，先看看这个风格长什么样。
第三步，如果满意，点「启用」，或者点「编辑VI」进去自己改。
第四步，改完点「保存」。

## ④ 预期结果
启用之后，你在做项目、生成课件的时候，就能在模板选择里看到它，生成出来的内容，就会用上这套风格。

## ⑤ 避坑提醒
注意，「删除」是不可撤销的，删除前会弹窗让你确认。另外，「在模板选择中显示」这个开关要打开，否则生成时，列表里看不到这个模板。
