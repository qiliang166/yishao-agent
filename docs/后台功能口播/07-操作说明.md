# 操作说明

## ① 一句话定位
操作说明，是系统自带的"使用手册"。它把每个板块怎么用，都写成了文档，你随时能查。

## ② 使用场景
当你不知道某个功能怎么用，又不想问人，就来操作说明翻一翻。

## ③ 分步操作
第一步，在左侧的章节列表里，点你想了解的那个章节，比如"项目管理首页"。
第二步，右侧就会显示对应的说明内容。
如果你想留一份离线看，就点左上角的「下载说明书」，会下载一个网页文件。
想打印出来，就点「打印」。

## ④ 预期结果
点开章节后，右侧立刻显示说明文字。点「下载说明书」，会得到一个网页文件，用浏览器就能打开。

## ⑤ 避坑提醒
注意，如果这里显示"暂无操作说明内容"，说明管理员还没写。这时候需要去「全局设置」里的「操作说明」标签页，先把内容编辑好。
