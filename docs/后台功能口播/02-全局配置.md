# 全局配置

## ① 一句话定位
全局配置，是你给整个系统定"默认规矩"的地方。用什么模型、提示词怎么写，都在这里统一设好。

## ② 使用场景
当你换了新的 AI 模型，或者想让所有新项目都用同一套提示词，就来全局配置改一次，一劳永逸。

## ③ 分步操作
进入页面后，顶部有两个标签：「模型设置」和「默认提示词」。
先看模型设置。第一步，点「+ 添加 LLM 提供商」。第二步，填「名称」「API Key」和「Base URL」。第三步，点「保存」。
再看默认提示词。第一步，点「默认提示词」标签。第二步，选「栏目配置」，下面有七个栏目，每个栏目都有一个「提示词」框。第三步，改完点「保存」。

## ④ 预期结果
模型保存后，这一行的状态会变成「已连接」，之后生成内容就用这个模型。提示词保存后，页面提示「已保存」，新建的项目会自动套用这套默认提示词。

## ⑤ 避坑提醒
注意，全局配置和后面的「全局设置」是两个不同的页面，别搞混。全局配置管"内容怎么生成"，全局设置管"系统本身怎么设置"。
