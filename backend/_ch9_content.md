## 第九章 模板管理（VI 视觉识别系统）

> **所属手册**：后台管理说明（管理员）

模板管理是系统的视觉识别（VI）管理中心。管理员在此管理设计风格、配色方案，以及完整的 VI 规范文档——这些共同决定 Stage 3 课件输出的最终视觉效果。

**进入方式**：左侧导航栏 →「📐 模板」。

**核心关系**：VI 规范定义"怎么呈现"（颜色/布局/排版），栏目提示词定义"生成什么"（内容/结构）。PPT 生成时，系统将 VI 规范文件注入提示词，AI 按视觉规则生成幻灯片。三者关系如下：

```
VI 规范（视觉规则）  +  栏目提示词（内容指令）  +  核心提示词（底层约束）
         ↓                      ↓                       ↓
         └──────────────────────┼───────────────────────┘
                                ↓
                     AI 生成完整 HTML 幻灯片
```

---

### 功能概述

**是什么**：管理 4 类设计风格的完整视觉识别系统——包含配色方案（每风格 13 色）、43+ 章 VI 规范文档、27 种页面类型模板、8 个文档构建块。Stage 3 用户从已启用风格中选择模板。

### 界面布局

**在哪里**：左侧导航栏 →「📐 模板」。

| 区域 | 控件 |
|------|------|
| 风格分组标签 | 商务专业(N) / 创意大胆(N) / 科技暗色(N) / 主题风格(N) |
| 风格卡片网格 | 4 列网格，每卡含渐变色条 / 名称 / 情绪描述 / 4 色预览 / 编辑VI / 预览VI / 提示词 / 启用开关 |
| 色系管理区 | 卡片展开后显示，含色系列表 / 颜色编辑器（13 色）/ 新增 / 删除 / 保存 |
| VI 编辑器弹窗 | 可拖拽缩放浮层，两级标签（7 类别→章节），编辑 / 预览 / 复制 / 下载 / 保存 |

### 一、风格分组与卡片管理

#### 功能概述

**是什么**：四个风格分组涵盖不同的视觉定位，每个分组下包含若干具体风格。风格卡片是进入色系管理和 VI 编辑的入口。

#### 界面布局

**在哪里**：「📐 模板」页面主体区域。页面顶部为 4 个分组标签（横向排列），下方为 4 列风格卡片网格。

每张卡片从上到下显示：渐变色条 → 风格名称（加粗）→ 情绪描述（灰色小字）→ 4 色预览（主色/辅色/强调色/背景色）→ 操作按钮行。

#### 参数说明

**四大分组**：

| 分组标签 | 英文标识 | 风格定位 | 适用场景 |
|---------|---------|---------|---------|
| 商务专业 | professional | 干净、权威、可信赖 | 企业培训、标准课程 |
| 创意大胆 | creative | 活力、鲜艳、表现力强 | 创意课程、营销培训 |
| 科技暗色 | tech | 前卫、精确、未来感 | 技术培训、产品讲解 |
| 主题风格 | thematic | 教育、奇幻、经典复古 | 教育课件、主题化培训 |

**风格卡片操作按钮**：

| 按钮 | 功能 |
|------|------|
| 编辑VI | 打开 VI 编辑器弹窗，编辑全部 43+ 章视觉规范 |
| 预览VI | 新窗口生成完整 VI 手册 HTML（含基础规范 + 全部 27 种页面类型预览） |
| 提示词 | 打开风格级提示词编辑器（prompt.md），控制 AI 的设计角色行为 |
| 启用/禁用 | 控制在 Stage 3 模板选择器中是否可见（开关控件） |

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 仅「已启用」（绿色开关）的风格会出现在 Stage 3 模板选择器中，禁用风格对使用者不可见 |
| 💡 技巧 | 风格级提示词（prompt.md）定义 AI 的**设计师角色**，区别于栏目配置中的内容生成提示词。前者管"长什么样"，后者管"写什么内容" |
| 💡 技巧 | 在已有风格基础上复制修改后重命名，可快速创建新视觉风格，无需从零搭建全部 VI 文档 |

#### 上下游功能

- **上游**：无直接上游，独立配置
- **下游**：色系管理、VI 编辑器、Stage 3 模板选择器

### 二、色系管理

#### 功能概述

**是什么**：每个 VI 风格包含若干配色方案（色系），每色系含 13 种颜色。Stage 3 生成时用户在色系中选择以改变课件色调。PPT 生成使用 `{{primary}}` 等占位符引用颜色，最终渲染替换为实际十六进制色值。

#### 界面布局

**在哪里**：点击风格卡片名称 → 展开色系管理区（内嵌在卡片下方）。

| 区域 | 控件 |
|------|------|
| 色系列表 | 横向排列的色系名标签，每个可点击展开 |
| 颜色编辑器 | 13 个颜色行，每行含颜色名 + 取色器 + 十六进制输入框 |
| 操作按钮 | + 新增色系 / 删除 / 设为默认 / 刷新 / 保存色系 |

#### 操作步骤

1. 点击风格名称 → 展开色系管理区
2. 点击色系名标签 → 展开颜色编辑器，显示 13 色配置
3. 修改颜色：点击取色器选择颜色，或直接在输入框输入十六进制值（如 `#1a365d`）
4. 点击「保存色系」→ 写入数据库

#### 参数说明

**13 种颜色定义**：

| 颜色名 | 键名 | 用途 |
|--------|------|------|
| 主色 | primary | 标题 / 强调 / 按钮 |
| 辅色 | secondary | 次要强调元素 |
| 强调色 | accent | 高亮 / CTA 元素 |
| 背景色 | background | 页面背景 |
| 文字色 | text | 正文颜色 |
| 卡片底色 | card_bg | 卡片容器背景 |
| 图表色 0-4（5色） | chart_0 ~ chart_4 | 图表数据系列配色 |
| 正面色 | semantic_positive | 达标 / 完成 / 正确 |
| 负面色 | semantic_negative | 警告 / 错误 / 风险 |

**色系操作**：

| 操作 | 说明 |
|------|------|
| + 新增色系 | 输入名称 → 自动复制当前色系全部 13 色值作为起点 |
| 删除 | 点击「删除」→ 至少保留一个色系（最后一个不可删除） |
| 设为默认 | 该色系标记为默认，Stage 3 自动选中此配色 |
| 刷新 | 重新从服务器加载，丢弃未保存的修改 |

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 颜色占位符 `{{primary}}` 等用于 VI 规范文档中。PPT 生成时系统自动替换为当前所选色系的实际 hex 值 |
| 💡 技巧 | 语义色有约束规则：正面色（绿色系）用于达标/完成/正确场景，负面色（红色系）用于警告/错误/风险场景。不要互换使用 |
| ⚠️ 警告 | 修改色系会影响该风格下**所有**使用此色系的 PPT 课件。变更前确认影响范围 |

#### 上下游功能

- **上游**：风格分组与卡片（色系属于具体风格）
- **下游**：Stage 3 色系选择器、PPT 颜色变量解析（`{{primary}}` → hex）

**是什么**：编辑风格完整视觉识别规范的核心工具。7 个类别覆盖 43+ 章规范文档，每章独立编辑。规范内容为 Markdown 格式，PPT 生成时按优先级（列覆写 > 页面类型 > 构建块 > 模板文件）注入 AI 提示词。

### 四、VI + 提示词 + PPT 生成关联

#### 功能概述

**是什么**：VI 规范、栏目提示词、核心提示词三者协同完成 PPT 课件生成。理解这个流程是管理好模板和提示词的关键——VI 管"长什么样"，栏目提示词管"写什么内容"，核心提示词管"底层约束"。

#### 完整生成流程（6 步）

```
① 用户在 Stage 3 选择模板（风格） + 色系

② 系统读取模板关联的 VI 风格目录：
   ├── prompt.md          → AI 设计角色（注入每张幻灯片系统提示词，管"设计风格"）
   ├── tokens.yaml        → 配色令牌（定义 {{primary}} 等占位符，最终替换为 hex）
   ├── vi.md              → 通用视觉规范（适用于全部页面类型）
   ├── index.md           → 27 种页面类型 + 8 构建块目录索引
   └── {type}.md          → 每种页面类型的专属视觉规范（如 cover.md, content.md）

③ 系统读取栏目配置的提示词 + SKILL：
   ├── col3/col4/col5 的栏目提示词 → 内容生成指令（管"写什么"）
   └── col3/col4/col5 的设计规则文件 → 文档级布局规则

④ Stage 5a（规划阶段）：
   输入：VI 通用规范 + tokens + 页面类型目录 + 文档内容
   输出：AI 生成幻灯片结构计划（每页什么类型、放什么内容）

⑤ Stage 5b（生成阶段，逐页执行）：
   每张幻灯片注入以下全部内容：
   ┌─────────────────────────────────────────────┐
   │ 第1层：风格角色（prompt.md）                   │
   │ 第2层：核心提示词 always/ 10 个文件             │
   │ 第3层：by_type/ 按类型提示词（条件注入）         │
   │ 第4层：by_feature/ 按功能提示词（条件注入）      │
   │ 第5层：by_layout/ 按布局提示词（条件注入）       │
   │ 第6层：页面类型专属 VI（{type}.md）             │
   │ 第7层：HTML/CSS 格式规范（format-spec.md）      │
   └─────────────────────────────────────────────┘
   → AI 生成完整 HTML 幻灯片

⑥ 后处理：
   颜色变量解析：{{primary}} → #1a365d → 最终课件 HTML
```

#### 三层分工对照

| 层次 | 来源 | 管什么 | 示例 |
|------|------|--------|------|
| VI 规范 | 模板管理（第九章） | 视觉呈现 | 主色 #1a365d、标题 32px、卡片圆角 8px |
| 栏目提示词 | 全局配置 → 栏目配置 | 内容生成 | "生成适合培训场景的教学课件" |
| 核心提示词 | 全局配置 → 核心配置 | 底层约束 | "每页必须有且仅有一个主标题" |

#### 提示与注意事项

| 类型 | 内容 |
