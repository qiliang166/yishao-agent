## 第五章 课件输出 — 5.1 文档课件

> **所属手册**：前台操作说明（使用者）

课件输出是五阶段流水线的第三阶段。本页面提供**文档课件输出**方式——基于 Stage 2 标准文档 + 选定 VI 模板，通过 AI 生成教学课件（SVG/PPTX 格式）。另外两种课件类型（分析PPT / 综合PPT）通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为控制面板，右栏为大纲编辑与课件预览面板。

---

### 功能概述

**是什么**：选择 VI 模板 → AI 生成课件大纲 → 编辑精修大纲 → AI 合成完整课件（SVG 幻灯片或 PPTX 文件），产出可直接用于教学的演示文稿。

**核心流程**：两步操作——先生成大纲，确认无误后再合成课件。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「③ 课件输出」，左栏子标签选择「文档课件」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 📄 生成课件 | 左栏 | 模板选择器、配色方案选择器、大模型选择器、「⚙温度设置」按钮、「📋 生成大纲」按钮、「📄 合成课件」按钮、取消按钮、有效性提示、日志面板 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 🤖 课件预览 | 右栏 | 大纲/JSON 标签切换、大纲文本编辑区、课件生成状态、幻灯片数量统计、操作按钮组（编辑/保存/清空/HTML编辑/预览/下载） |

### 操作步骤

1. **选择模板**：在「选择模板」区域点击 VI 模板卡片，预览图显示在模板预览区。模板来自「模板管理」中已上传的文档课件模板
2. **选择配色方案**（可选）：如果模板有多个配色方案，会显示配色选择器，点击色块切换
3. **选择大模型**：在「大模型」下拉框中选定 LLM 提供商和模型
4. **设置温度**（可选）：点击「⚙温度设置」→ 弹出温度设置对话框，分五个标签页：
   - 「阶段速设」：阶段级温度（大纲阶段/生成阶段/审核阶段），每个滑块联动对应子字段
   - 「内容生成」：标准文档生成温度
   - 「生成大纲」：关键词提取、研究扩展、大纲生成、内容填充四个子步骤温度
   - 「合成PPT」：卡片生成、HTML 合成两个子步骤温度
   - 「后台自动」：SVG 批量/单张、审核、修正、整体优化等子步骤温度
   - 提供快速预设按钮：「推荐默认」「全部 0.3」「全部 0.7」「全部 1.0」
   - 点击「应用」保存设置
5. **生成大纲**：点击「📋 生成大纲」→ 按钮变为「⏳ 生成中...」→ 日志面板实时显示进度
6. **编辑大纲**（重要）：大纲生成后显示在右栏「大纲内容」标签页中
   - 点击「✏ 编辑」进入编辑模式，可直接修改大纲文本
   - 点击「👁 查看」回到只读模式
   - 点击「JSON」标签可查看/编辑大纲的 JSON 结构数据
   - 点击「💾 保存」保存修改后的大纲
7. **合成课件**：确认大纲无误后，点击「📄 合成课件」→ 按钮变为「⏳ 合成中...」→ 顶部进度条显示「PPT 合成中」及页数进度
8. **查看和下载结果**：合成完成后，右栏显示「已生成 N 页课件」及操作按钮：
   - 「预览」：在新窗口打开课件预览
   - 「⬇ SVG ZIP」：下载 SVG 格式完整课件包
   - 「⬇ PPTX」：下载 PPTX 格式文件
   - 「⬇ HTML」：下载 HTML 格式文件
   - 「HTML编辑」：打开高级编辑面板（SlideEditModal），支持预览/源码/重新生成

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 模板 | VI 视觉模板，决定课件的外观风格 | 选择与培训主题匹配的模板 |
| 配色方案 | 模板的颜色变体 | 根据品牌或主题选择 |
| 大模型 | 执行大纲生成和课件合成的 LLM | 选择已启用的模型 |
| 温度（多项） | 控制各子步骤的输出随机性 | 使用「推荐默认」预设，或根据效果微调 |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| ⚠️ 警告 | 课件合成过程较长（通常 1-5 分钟），切换栏目不影响生成，但不要关闭页面 |
| 📌 注意 | 必须先有 Stage 2 的标准文档内容，否则无法选择数据源 |
| 💡 技巧 | 大纲质量决定课件质量——生成大纲后务必逐条检查，手动修正不准确的内容再合成 |
| 💡 技巧 | 温度设置中「推荐默认」预设经过调优，首次使用建议保持默认 |
| 💡 技巧 | SVG 格式课件可直接在浏览器预览，效果与最终展示一致；PPTX 格式适合在 PowerPoint 中进一步编辑 |
| 📌 注意 | 生成过程中可点击「取消生成」中止，已生成的部分不会保留 |
