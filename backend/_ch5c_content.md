## 第五章 课件输出 — 5.3 综合PPT

> **所属手册**：前台操作说明（使用者）

课件输出是五阶段流水线的第三阶段。本页面提供**综合PPT输出**方式——基于 Stage 2 综合文档 + 选定 VI 模板，通过 AI 生成综合性演示文稿。另外两种课件类型（文档课件 / 分析PPT）通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为控制面板，右栏为大纲编辑与 PPT 预览面板。

---

### 功能概述

**是什么**：选择 VI 模板 → AI 生成综合型 PPT 大纲 → 编辑精修大纲 → AI 合成完整幻灯片，将 Stage 2 的综合文档（手册格式，含背景知识和要点）转化为全面覆盖的演示文稿。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「③ 课件输出」，左栏子标签选择「综合PPT」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 📚 综合PPT | 左栏 | 模板选择器、配色方案选择器、大模型选择器、「⚙温度设置」按钮、「📋 生成大纲」按钮、「📌 合成PPT」按钮、取消按钮、有效性提示（请选择模板/请先生成综合文档/请选择大模型）、日志面板 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 🤖 PPT 预览 | 右栏 | 大纲/JSON 标签切换、大纲文本编辑区、PPT 生成状态、幻灯片数量统计、操作按钮组 |

### 操作步骤

1. **选择模板**：在「选择模板」区域点击综合PPT模板卡片（来自模板管理中上传的综合PPT类型模板）
2. **选择配色方案**（可选）：如果模板有多个配色方案，点击色块选择
3. **选择大模型**：在「大模型」下拉框中选定 LLM 提供商和模型
4. **设置温度**（可选）：点击「⚙温度设置」→ 在五标签页对话框中微调各子步骤温度参数
   - 「阶段速设」：大纲阶段（默认 0.3）、生成阶段（默认 0.7）、审核阶段（默认 0.3）
   - 「生成大纲」：关键词（0.3）、研究（0.7）、大纲（1.0）、填充（1.0）
   - 「合成PPT」：卡片（0.7）、HTML（0.8）
   - 「后台自动」：SVG 批量/单张、审核、修正、整体优化等
   - 快速预设按钮可一键设置所有温度
5. **生成大纲**：点击「📋 生成大纲」→ 等待 AI 分析综合文档内容并生成 PPT 大纲结构
6. **编辑大纲**：在右栏检查和修改大纲内容
   - 大纲内容标签页：文本编辑模式
   - JSON 标签页：结构化数据编辑模式
   - 修改后点击「💾 保存」
7. **合成PPT**：确认大纲无误后，点击「📌 合成PPT」→ 顶部进度条显示合成进度（页数/总页数）→ 等待完成
8. **查看和下载**：
   - 「预览」：新窗口打开课件预览
   - 「⬇ SVG ZIP」：下载 SVG 格式完整课件包（含图片资源）
   - 「⬇ PPTX」：下载 PPTX 格式（可在 PowerPoint 中编辑）
   - 「⬇ HTML」：下载 HTML 格式
   - 「HTML编辑」：打开 SlideEditModal 高级编辑面板，支持预览/源码编辑/指定页面重新生成/重新着色

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 模板 | 综合PPT 类型的 VI 模板 | 选择与综合主题风格匹配的模板 |
| 配色方案 | 模板的颜色变体 | 根据品牌或主题选择 |
| 大模型 | 执行大纲和 PPT 生成的 LLM | 选择已启用的模型 |
| 温度 | 多字段温度参数（13个字段，5个标签页） | 首次使用建议保持「推荐默认」 |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 综合文档内容较多（含背景知识和要点），大纲生成和PPT合成时间可能比分析和标准更长 |
| 💡 技巧 | 综合PPT 适合全面知识覆盖的培训场景，大纲阶段建议按知识模块合理分组 |
| 💡 技巧 | 温度设置中「阶段速设」标签页可快速联动设置所有子步骤温度，适合批量调整 |
| 💡 技巧 | HTML编辑 模式下的「重新生成」功能可指定单个页面重新生成，不影响其他页面 |
| 💡 技巧 | SVG 格式支持在线预览，下载前可先预览确认效果 |
| 📌 注意 | 生成过程中可点击「取消生成」中止，切换栏目不影响任务进行 |
