## 前台操作说明

> 本手册面向**系统使用者**（培训师、教案制作人员），介绍如何使用智绘教案系统完成从素材到成品的全流程制作。系统配置与管理请参阅《后台管理说明》。

---

## 第一章 产品概述与工作区管理

### 1.1 产品简介

**是什么**：智绘教案系统（Yishao Agent）是一套 AI 驱动的教案与课件自动生成平台。使用者提供原始素材（视频链接、文字内容、文件），系统自动完成「素材提取 → 文档生成 → 课件输出 → 演讲配音」的全流程制作，将原本需要数天完成的教案课件制作缩短至数十分钟。

**适用场景**：

| 场景 | 示例 |
|------|------|
| 企业内训 | 门店操作规范、产品知识培训、服务流程培训 |
| 教育培训 | 课程教案、教学课件、习题解析 |
| 餐饮行业 | 菜品制作培训、后厨流程标准化、食品安全培训 |
| 零售行业 | 商品知识培训、销售话术培训、陈列规范培训 |

### 1.2 核心功能概览

| 功能模块 | 做什么 | 输入 | 输出 |
|---------|--------|------|------|
| 素材输入 | 从视频、文本、文件中提取原始内容 | 视频链接 / 文字 / .txt/.md/.docx 文件 | 结构化文本素材 |
| 文档生成 | AI 自动撰写三种类型培训文档 | 素材文本 | 标准文档 / 分析文档 / 综合文档 |
| 课件输出 | 文档转 PPT/HTML 课件 | Markdown 文档 | SVG / PPTX / HTML 课件文件 |
| 演讲课件 | 生成演讲稿并合成语音 | 文档内容 | 口播稿文本 + MP3/WAV 音频 |
| 输出管理 | 统一浏览和下载所有产出 | 各阶段产物 | 下载文件、批量 ZIP 打包 |

### 1.3 系统架构

系统采用三层组织：

```
工作区（顶层容器）
  └── 项目明细（内容单元）
       └── 五阶段流水线
            ① 素材输入 → ② 文档生成 → ③ 课件输出 → ④ 演讲课件 → ⑤ 输出列表
```

| 层级 | 说明 | 举例 |
|------|------|------|
| 工作区 | 最高层级，隔离不同业务场景 | 「餐饮培训」「门店运营」「2026 春季课程」 |
| 项目明细 | 工作区下的具体内容单元 | 「红烧肉制作教程」「迎宾服务规范」 |
| 五阶段流水线 | 每个项目从素材到成品的处理管线 | 视频提取 → 文档生成 → PPT 输出 → 语音合成 |

**重要关系**：删除工作区将级联删除其下全部项目明细及所有产出文件，不可恢复。

### 1.4 工作区管理

#### 功能概述

**是什么**：工作区管理是使用者进入系统后的第一个操作界面，用于创建、查找、进入和删除工作区。每个工作区代表一个独立的业务场景，其下的项目明细和配置互不干扰。

#### 界面布局

**在哪里**：登录后默认进入管理首页，页面结构从上到下为：

| 区域 | 控件 | 说明 |
|------|------|------|
| 标题栏 | 搜索框 | 左侧，占位文字「搜索项目...」，最大宽度 300px |
| 标题栏 | ? 帮助按钮 | 中间，点击查看当前页面的操作说明 |
| 标题栏 | 「+ 新建项目」按钮 | 右侧，蓝色主按钮，创建新工作区 |
| 卡片网格 | 4 列工作区卡片 | 每张卡片为一个工作区，每页最多 16 个 |
| 分页栏 | 翻页按钮 + 页码 | 仅当超过 16 个工作区时显示 |
| 统计脚注 | 「共 N 个项目」 | 显示工作区总数 |

**工作区卡片**上显示的信息（从上到下）：

1. **顶部行**：左侧 Logo 图片（未设置时显示 📁 图标）+ 右侧状态徽章
2. **名称**：15px 加粗文字
3. **底部操作行**：「进入」按钮（左侧） + 「删除」按钮（右侧，红色文字）

**状态徽章**样式：

| 状态 | 显示文字 | 背景色 | 文字色 |
|------|---------|--------|--------|
| draft | 草稿 | 浅灰色 (rgba(148,163,184,0.12)) | 灰色 |
| completed | 已完成 | 浅绿色 (rgba(34,197,94,0.12)) | 绿色 |

**卡片交互**：
- 鼠标悬停时卡片上浮 2px（`translateY(-2px)`），出现浅阴影
- 点击卡片主体（除操作按钮外）等同于点击「进入」

#### 操作步骤

##### 创建工作区

1. 点击页面右上角「+ 新建项目」按钮 → 弹出创建对话框（宽度 440px，居中覆盖显示）
2. 在「项目名称」输入框中输入名称（**必填**）
   - 占位提示文字：「如：门店培训、餐饮教案」
   - 名称不能为空，否则「创建」按钮保持禁用状态
3. （可选）设置项目图标：
   - 点击「上传图片」→ 选择本地图片文件 → 上传后显示 48×48 预览图
   - 点击「移除」可清除已设置的图片
   - 也可在名称中使用 emoji（如 🍳、📚）作为简易图标
4. （可选）在「项目简介」文本框中输入描述文字
   - 占位提示文字：「简要描述该项目的用途和内容...」
   - 文本框为 4 行高度，支持手动拖拽右下角调整高度
5. （可选）在「状态」下拉框中选择初始状态：「草稿」或「已完成」
   - 默认选择「草稿」
6. 点击「创建」按钮 → 按钮文字变为「创建中...」→ 创建成功后自动跳转至该工作区内部

##### 搜索工作区

1. 在顶部标题栏的搜索框中输入关键词
2. 系统**实时**筛选名称中包含关键词的工作区（不区分大小写，无需按回车）
3. 清空搜索框即恢复当前页完整列表

📌 **注意**：搜索范围仅限于当前显示页面。如有多个分页，需先翻到目标页再搜索。

##### 进入工作区

- **方式一**：点击工作区卡片主体区域（除底部按钮外的任意位置）
- **方式二**：点击卡片底部的「进入」按钮

两种方式效果完全相同，均跳转至该工作区的项目明细列表页面。

##### 删除工作区

1. 点击目标卡片右下角的「删除」按钮（红色文字）
2. 系统弹出确认框：
   - 标题：「确认操作」
   - 内容：「确认删除「{工作区名称}」？其下所有明细将被一并删除，此操作不可撤销。」
3. 点击「确认」→ 删除完成，列表自动刷新
4. 点击「取消」→ 放弃操作

⚠️ **严重警告**：删除操作**不可撤销**。该工作区下的所有项目明细，以及明细中全部阶段的已保存内容（素材文本、生成文档、PPT 课件、音频文件）将被**一并永久删除**。执行前务必逐一核实工作区内无需要保留的数据。

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 💡 技巧 | 命名建议使用「场景 + 时间」格式，如「2026 春季数学课」「餐饮后厨 Q3」，便于识别和搜索 |
| 💡 技巧 | Logo 支持三种来源：emoji、图片 URL、本地上传。推荐使用 1:1 正方形图片 |
| 💡 技巧 | 建议先在「草稿」状态下搭建工作区内容，全部完成后切换为「已完成」状态 |
| 📌 注意 | 每页最多显示 16 个工作区，超出自动分页。底部分页栏提供「上一页」「第 X/Y 页」「下一页」控件 |
| 📌 注意 | 从工作区内部返回首页时，工作区列表会自动刷新，无需手动刷新浏览器 |
| ⚠️ 警告 | 删除不可逆。确认框已明确提示全部后果，请仔细阅读后再点击「确认」 |

#### 上下游功能

- **无上游依赖**：工作区是系统的顶层入口，无需前置操作
- **下游**：进入工作区后管理项目明细（见第二章）
