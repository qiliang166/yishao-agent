## 十五、配图/插图规范（铁律第 6 条执行细则）

### 铁律

**1280×720 画布的内容区 (y:60-660, x:60-1220) 必须被完全填满。任何 >80px 的连续空白区域 = 设计失败。代码会自动检测，违规将强制重试。**

### 何时必须填充

- **封面/总结页**：必须有大面积装饰（光晕、大圆、几何图形、网格纹理）+ `{{image:}}` 背景图占位符
- **内容页右侧留白 >200px**：必须插入 `{{image:}}` 配图占位符或大号 SVG 插图
- **内容页下方留白 >80px**：必须添加图表、插图或装饰图形填充，不得保留空白
- **卡片区不足导致留白 >80px**：必须添加主题相关插图填充
- **抽象概念/流程**：用 SVG 矢量插图辅助说明

### 填充方案（按优先级执行）

1. 封面/image_hero/image_grid 页 → **必须**使用 `{{image:详细描述}}` 占位符
2. 有数据 → 加图表（big_number / progress_bar / donut / bar）
3. 有流程 → 加 timeline 或步骤 SVG
4. 有对比 → 加 two_column 对照插图
5. 以上都不适用 → 加大号 SVG 主题装饰插图（≥200px 宽，含几何图形+图标）或 `{{image:描述}}` 占位符

### `{{image:}}` 占位符 vs SVG 插图

| 类型 | 用途 | 由谁生成 |
|------|------|----------|
| `{{image:描述}}` | 真实照片、写实配图、背景图 | 图片生成模型 |
| 内联 SVG | 图表、几何装饰、图标、流程图 | 你直接绘制 |

**封面页、image_hero、image_grid 必须优先使用 `{{image:}}` 占位符。** SVG 插图仅用于图表和装饰。

### 插图风格

插图风格跟随模版：
- tech/geometric 风格：SVG 矢量抽象几何图形（opacity 0.08-0.5）
- illustrative 风格：手绘感插画
- photographic 风格：`{{image:}}` 写实配图 + 深色蒙层
