## 第三章 素材输入 — 3.1 视频提取

> **所属手册**：前台操作说明（使用者）

素材输入是五阶段流水线的第一阶段。本页面提供**视频提取**方式——从在线视频平台下载视频，通过 ASR 语音识别转为文字，再通过 AI 整理为结构化文档。另外两种方式（文字输入 / 文件提取）通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为控制面板，右栏为 AI 生成结果面板。

---

### 功能概述

**是什么**：粘贴视频链接 → 系统下载视频并语音识别 → AI 将识别结果整理为结构化文档。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「① 素材输入」，左栏子标签选择「视频提取」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 🤖 模型选择 | 左栏顶部 | LLM 下拉选择器（含提供商/模型名称）、温度输入框（0-2，步进 0.1，默认 0.3） |
| 📺 视频提取 | 左栏 | 视频链接输入框、ASR 提供商选择器、ASR 模型选择器、「▶ 下载并识别」按钮、「📺 播放校验」按钮、「⚙ 整理文档」按钮 |
| 📝 提取的原始文本 | 左栏（下载完成出现） | 源文本标签（合并版/语音识别/字幕）、文本编辑区、清空和保存按钮 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 🤖 AI 生成结果 | 右栏 | 整理后文本显示区、「📥 保存到项目」「⚡ 生成所有文案」、保存和清空按钮 |

### 操作步骤

1. **选择大模型**：在「🤖 模型选择」下拉框中选定 LLM 提供商和模型
2. **调节温度**（可选）：在温度输入框中调整（默认 0.3，整理任务建议 0.3-0.5）
3. **粘贴视频链接**：在链接输入框中粘贴视频 URL
   - 占位提示：「粘贴视频链接（支持抖音/B站/YouTube等）」
4. **选择 ASR 引擎**（如有多个）：分别选择 ASR 提供商和识别模型
5. **下载并识别**：点击「▶ 下载并识别」→ 进度条显示「⏳ 正在下载... X%」→ 完成后显示「✅ 下载完成」
6. **校验内容**（可选）：点击「📺 播放校验」→ 弹出视频播放窗口，左播右文对照核实
7. **切换源文本**（下载完成）：编辑区顶部出现「合并版」「语音识别」「字幕」三个标签，点击切换不同版本的提取文本
8. **编辑文本**（可选）：直接在编辑区修改提取内容
9. **AI 整理**：点击「⚙ 整理文档」→ 按钮变为「⏳ 生成中...」→ 结果显示在右栏
10. **保存结果**：点击保存按钮或「📥 保存到项目」

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 大模型 | 执行文本整理的 LLM | 选择已启用的模型 |
| 温度 | 输出随机性 | 0.3-0.5（整理偏规范，较低温度） |
| ASR 提供商 | 语音识别服务 | 选择已启用且推荐的服务商 |
| ASR 模型 | 识别模型 | fun-asr 为默认推荐 |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| ⚠️ 警告 | 大视频下载可能需要数分钟，请耐心等待 |
| 📌 注意 | 部分平台视频（会员、私有）无法下载 |
| 💡 技巧 | 使用 10 分钟以内的视频，过长会降低识别质量 |
| 💡 技巧 | 「合并版」综合 ASR 和字幕优势，推荐作为整理素材 |
| 💡 技巧 | ASR 对专业术语识别可能有误，建议播放校验后修正 |
| 📌 注意 | 下载中可点「取消」，已下载文本保留在编辑区 |

### 项目保存路径

**是什么**：设置当前项目的文件存储目录，覆盖全局默认路径。输入框显示当前路径（默认继承全局设置），点击「📂」在文件管理器中打开当前目录。修改路径后点击「保存」生效。路径规则：`保存路径 / 项目名称 /`。此功能在三个子标签（视频提取/文字输入/文件提取）间共享。
