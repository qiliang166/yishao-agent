## 第三章 素材输入 — 3.3 文件提取

> **所属手册**：前台操作说明（使用者）

素材输入是五阶段流水线的第一阶段。本页面提供**文件提取**方式——上传本地文件（.txt / .md / .docx），自动读取内容后再通过 AI 整理为结构化文档。另外两种方式（视频提取 / 文字输入）通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为控制面板，右栏为 AI 生成结果面板。

---

### 功能概述

**是什么**：上传本地文件 → 系统自动读取文本内容 → 用户编辑确认 → AI 整理为结构化文档。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「① 素材输入」，左栏子标签选择「文件提取」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 🤖 模型选择 | 左栏顶部 | LLM 下拉选择器、温度输入框（0-2，步进 0.1） |
| 📄 文件提取 | 左栏 | 文件选择按钮（接受 .txt/.md/.docx）、「⚙ 整理文档」按钮 |
| 📝 文件原始内容 | 左栏（读取后出现） | 内容展示区（最小高度 120px）、「🗑 清空」、保存按钮 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 🤖 AI 生成结果 | 右栏 | 整理后文本、「📥 保存到项目」「⚡ 生成所有文案」、保存和清空按钮 |

### 操作步骤

1. **选择大模型**：在「🤖 模型选择」下拉框中选定 LLM
2. **选择文件**：点击文件选择按钮 → 选取本地 .txt / .md / .docx 文件
   - 提示文字：「支持 .txt / .md / .docx 文件，读取后内容在下方编辑」
   - 文件读取后自动显示在「📝 文件原始内容」区域
3. **编辑内容**（可选）：在下方的文本编辑区手动修改提取的文本
4. **AI 整理**：点击「⚙ 整理文档」→ 等待生成完成
5. **保存结果**

### 参数说明

| 参数 | 说明 |
|------|------|
| 支持格式 | .txt（纯文本）、.md（Markdown）、.docx（Word 文档） |
| 文件大小 | 建议不超过 10MB |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | .docx 仅提取纯文本内容，表格、图片、复杂排版无法保留 |
| 💡 技巧 | 使用 .md 格式可保留标题、列表等结构标记，AI 整理效果更佳 |
| 💡 技巧 | 文本文件建议使用 UTF-8 编码，避免中文乱码 |
