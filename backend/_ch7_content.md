## 第七章 输出管理

> **所属手册**：前台操作说明（使用者）

输出管理是五阶段流水线的第五阶段，汇总展示当前项目下所有阶段产出的文件，提供统一的管理、搜索、下载和删除功能。

页面采用**单栏全宽布局**（无左右分栏），文件按类别分组展示。

---

### 功能概述

**是什么**：集中管理当前项目在所有阶段（素材输入 → 文档生成 → 课件输出 → 演讲课件）产出的全部文件，支持按类别分组浏览、关键词搜索、单个/批量下载和删除。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「⑤ 输出列表」。

| 区域 | 位置 | 控件 |
|------|------|------|
| 标题栏 | 页面顶部 | 项目名称标题、? 帮助按钮、「🔄 刷新」按钮、「📦 一键下载」或「📥 下载选中(N)」按钮 |
| 工具栏 | 标题栏下方 | 搜索框「搜索文件名...」、文件数量统计、全选/取消全选按钮、「删除选中(N)」按钮、「全部展开/折叠」按钮 |
| 文件列表 | 页面主体 | 按类别分组：素材输入（📥）、文档生成（📝）、课件输出（📌）、演讲课件（🎵） |
| 状态提示 | 列表为空时 | 「暂无产出物」居中提示 |

**文件行显示信息**（每行从左到右）：

| 元素 | 说明 |
|------|------|
| 复选框 | 用于批量操作选择 |
| 文件类型图标 | 📥 素材输入 / 📝 文档生成 / 📌 课件输出 / 🎵 演讲课件 / 📄 其他 |
| 文件名 | 显示名称，过长自动省略 |
| 修改日期 | 最后修改日期（本地格式） |
| 文件大小 | B/KB/MB 自动单位 |
| 播放按钮 | 仅音频文件（.mp3/.wav）显示「▶/⏸」播放/暂停 |
| 下载按钮 | 「下载」按钮 |
| 删除按钮 | 「✕」删除按钮 |

### 操作步骤

#### 浏览文件

1. 进入 Stage 5，系统自动加载文件列表，按类别分组展开
2. 点击类别标题行（如「📥 素材输入 (3)」）展开/折叠该组
3. 点击「全部展开」或「全部折叠」批量操作所有分组
4. 点击「🔄 刷新」重新加载最新文件列表

#### 搜索文件

1. 在搜索框中输入关键词 → 实时筛选文件名
2. 搜索不区分大小写，匹配文件名或显示名称
3. 工具栏显示筛选结果：「N / M 个文件 · 总大小」
4. 清空搜索框恢复完整列表

#### 下载文件

- **单个下载**：点击文件行右侧的「下载」按钮 → 浏览器自动下载
- **一键下载全部**：点击顶部「📦 一键下载 (N)」按钮 → 所有文件打包为 ZIP 并下载
- **批量下载**：勾选目标文件 → 点击顶部出现的「📥 下载选中 (N)」→ 选中文件打包为 ZIP 并下载

#### 删除文件

- **单个删除**：点击文件行右侧的「✕」→ 弹出确认框 → 确认后永久删除
- **批量删除**：勾选目标文件 → 点击工具栏「删除选中 (N)」（红色按钮）→ 确认后批量删除

#### 播放音频

- 点击音频文件（.mp3/.wav）旁的「▶」按钮 → 在线播放
- 点击「⏸」停止播放

### 文件分类规则

| 类别 | 图标 | 包含文件 |
|------|------|---------|
| 素材输入 | 📥 | Stage 1 产出的整理后文本、原始素材记录 |
| 文档生成 | 📝 | Stage 2 产出的标准/分析/综合文档（.txt/.docx） |
| 课件输出 | 📌 | Stage 3 产出的 PPT/HTML/SVG/PNG/JPG 课件文件 |
| 演讲课件 | 🎵 | Stage 4 产出的演讲稿（.txt）和音频文件（.mp3/.wav） |
| 其他 | 📄 | 不属于以上类别的文件 |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| ⚠️ 警告 | 删除操作不可恢复，删除前请确认文件不再需要 |
| 📌 注意 | 删除文件仅从输出列表中移除，不影响各 Stage 的步骤数据（可在对应 Stage 中重新生成） |
| 💡 技巧 | 完成所有阶段后，使用「一键下载」快速打包所有产出物 |
| 💡 技巧 | 使用搜索功能快速定位特定文件，尤其在文件数量较多时 |
| 📌 注意 | 输出列表每次进入时会重新从服务器加载，生成新文件后如果未显示，点击「🔄 刷新」 |

### 上下游功能

- **上游**：Stage 1-4 所有产出物（第三至六章）
- **下游**：无（终端阶段，产出物可直接用于教学）
