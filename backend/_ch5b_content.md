## 第五章 课件输出 — 5.2 分析PPT

> **所属手册**：前台操作说明（使用者）

课件输出是五阶段流水线的第三阶段。本页面提供**分析PPT输出**方式——基于 Stage 2 分析文档 + 选定 VI 模板，通过 AI 生成分析型演示文稿。另外两种课件类型（文档课件 / 综合PPT）通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为控制面板，右栏为大纲编辑与 PPT 预览面板。

---

### 功能概述

**是什么**：选择 VI 模板 → AI 生成分析型 PPT 大纲 → 编辑精修大纲 → AI 合成完整幻灯片，将 Stage 2 的分析文档转化为可视化的演示文稿。

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「③ 课件输出」，左栏子标签选择「分析PPT」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 📌 分析PPT | 左栏 | 模板选择器、配色方案选择器、大模型选择器、「⚙温度设置」按钮、「📋 生成大纲」按钮、「📌 合成PPT」按钮、取消按钮、有效性提示（请选择模板/请先生成分析文档/请选择大模型）、日志面板 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 🤖 PPT 预览 | 右栏 | 大纲/JSON 标签切换、大纲文本编辑区、PPT 生成状态、幻灯片数量统计、操作按钮组 |

### 操作步骤

1. **选择模板**：在「选择模板」区域点击分析PPT模板卡片（来自模板管理中上传的分析PPT类型模板）
2. **选择配色方案**（可选）：如果模板有多个配色方案，点击色块选择
3. **选择大模型**：在「大模型」下拉框中选定 LLM 提供商和模型
4. **设置温度**（可选）：点击「⚙温度设置」→ 在五标签页对话框中微调各子步骤温度参数
   - 提供「推荐默认」「全部 0.3」「全部 0.7」「全部 1.0」快速预设
5. **生成大纲**：点击「📋 生成大纲」→ 等待 AI 分析分析文档内容并生成 PPT 大纲结构
6. **编辑大纲**：在右栏「大纲内容」标签页中检查和修改大纲
   - 点击「✏ 编辑」切换编辑模式
   - 点击「JSON」标签查看结构化大纲数据
   - 修改后点击「💾 保存」
7. **合成PPT**：确认大纲无误后，点击「📌 合成PPT」→ 顶部显示进度条 → 等待幻灯片生成
8. **查看和下载**：合成完成后可预览、下载 SVG ZIP / PPTX / HTML，或打开 HTML 编辑器进行高级编辑

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 模板 | 分析PPT 类型的 VI 模板 | 选择与分析主题风格匹配的模板 |
| 配色方案 | 模板的颜色变体 | 根据品牌或分析主题选择 |
| 大模型 | 执行大纲和 PPT 生成的 LLM | 选择已启用的模型 |
| 温度 | 多字段温度参数（13个字段） | 使用「推荐默认」预设 |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 必须先有 Stage 2 的分析文档（4.2）内容，否则无法生成 |
| 💡 技巧 | 分析PPT 侧重于原理和方法论的可视化呈现，大纲阶段应关注逻辑结构和层次关系 |
| 💡 技巧 | 大纲编辑支持 JSON 模式，适合需要精确控制幻灯片结构的场景 |
| 📌 注意 | 生成过程中切换栏目不影响任务进行，顶部进度条会持续更新 |
