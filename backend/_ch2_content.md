## 第二章 项目明细管理

> **所属手册**：前台操作说明（使用者）

---

### 功能概述

**是什么**：项目明细是工作区下的具体内容单元。每个项目明细拥有独立的五阶段流水线（素材输入 → 文档生成 → 课件输出 → 演讲课件 → 输出列表），用于完成一个培训主题的完整内容制作。

**进入方式**：在管理首页点击任意工作区卡片，即进入该工作区的项目明细列表页面。

### 界面布局

**在哪里**：进入工作区后，页面从上到下依次为：

| 区域 | 位置 | 包含控件 |
|------|------|---------|
| 标题栏 | 页面顶部 | 搜索框「搜索明细...」（左侧）、? 帮助按钮（中间）、「+ 新建明细」按钮（右侧） |
| 批量工具栏 | 标题栏下方 | 仅在勾选项目后出现，显示「已选 N 项」及批量操作按钮 |
| 项目列表 | 页面主体 | 每行一张项目卡片，每页最多 20 条 |
| 分页栏 | 列表下方 | 「上一页」「第 X/Y 页」「下一页」（超过 20 条时显示） |
| 统计脚注 | 页面底部 | 「共 N 条明细」或「没有匹配的明细」 |

**项目卡片**每行显示的信息（从左到右）：

| 元素 | 说明 |
|------|------|
| ▶/▼ 展开箭头 | 点击展开该项目的输出文件列表 |
| 行号 | 当前页内序号 |
| 复选框 | 用于批量操作选择 |
| 项目编号 | 如 KH260701-0001，系统自动生成 |
| 项目名称 | 加粗显示，点击可进入五阶段流水线 |
| 📋 图标 | 仅当该项目从其他项目复制配置时显示 |
| 状态标签 | 「草稿」（灰色）或「已完成」（绿色），点击可快速切换 |
| 更新日期 | 最后修改日期 |
| 操作按钮组 | 「📦 输出」「复制」「删除」「锁定」 |

### 操作步骤

#### 创建项目明细

1. 点击页面右上角「+ 新建明细」按钮 → 弹出创建对话框（宽度 460px）
2. 在「明细名称」输入框中输入项目名称（**必填**）
   - 占位提示文字：「输入明细名称」
   - 名称不能为空，否则「创建」按钮保持禁用
3. （可选）勾选「从已有明细复制配置」复选框：
   - 展开源明细选择器
   - 在搜索框中输入关键词查找源项目
   - 下拉列表显示匹配的项目（含编号、名称、状态、创建日期）
   - 点击选中目标项目 → 显示「已选择：{项目名称}」→ 点击「清除」可取消
   - 作用：新项目将复用源项目的提示词和模型设置，避免重复配置
4. 点击「创建」按钮 → 按钮变为「创建中...」→ 创建成功后自动进入新项目的五阶段流水线

#### 搜索项目明细

1. 在标题栏搜索框「搜索明细...」中输入关键词
2. 系统实时按项目名称筛选（不区分大小写，无需按回车）
3. 清空搜索框恢复完整列表

📌 **注意**：搜索仅在当前页内过滤。跨页搜索需先翻页。

#### 查看输出文件

1. 点击项目卡片左侧的 ▶ 箭头 → 箭头变为 ▼，展开文件列表面板
2. 文件按类别分组显示：

| 分组 | 图标 | 包含内容 |
|------|------|---------|
| 素材输入 | 📥 | Stage 1 产出的整理后文本 |
| 文档生成 | 📝 | Stage 2 产出的标准/分析/综合文档 |
| 课件输出 | 📌 | Stage 3 产出的 PPT/HTML 课件 |
| 演讲课件 | 🎵 | Stage 4 产出的演讲稿和音频 |

3. 每组可点击标题展开/折叠
4. 每个文件显示：类型图标、文件名、修改日期、文件大小
5. 音频文件旁显示 ▶ 播放按钮，可在线试听
6. 使用文件搜索框「搜索文件...」可在展开面板内筛选文件

#### 下载文件

**单个下载**：点击文件行右侧的 ⬇ 按钮 → 浏览器自动下载

**批量下载**：
1. 勾选目标文件左侧的复选框
2. 点击面板顶部出现的「📥 下载选中 (N)」按钮
3. 系统将选中文件打包为 ZIP 并自动下载

#### 批量操作

1. 勾选目标项目左侧的复选框（或点击顶部「全选」勾选当前页全部项目）
2. 标题栏下方出现批量工具栏，显示「已选 N 项」及操作按钮：

| 按钮 | 效果 |
|------|------|
| 「批量完成」 | 将选中项目状态标记为「已完成」 |
| 「批量草稿」 | 将选中项目状态恢复为「草稿」 |
| 「批量锁定」 | 锁定选中项目，禁止修改和删除 |
| 「批量解锁」 | 解除锁定 |
| 「删除选中(N)」 | 批量删除（红色按钮，跳过已锁定项目） |

3. 点击「删除选中」时：
   - 已锁定的项目自动跳过，提示跳过的项目名称
   - 弹出确认框确认删除数量
   - 确认后永久删除

#### 复制项目

- 点击项目卡片右侧的「复制」按钮 → 立即复制该项目（含全部配置），列表自动刷新

#### 切换状态

- 点击项目卡片上的状态标签（「草稿」或「已完成」）→ 立即切换，无需确认

#### 锁定/解锁

- 点击项目卡片右侧的「锁定」→ 变为「已锁定」（橙色文字），项目无法被删除
- 再次点击「已锁定」→ 解除锁定

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 💡 技巧 | 创建同类培训项目时，勾选「从已有明细复制配置」可复用提示词和模型设置，节省配置时间 |
| 💡 技巧 | 定期清理不再需要的输出文件，释放存储空间 |
| ⚠️ 警告 | 删除项目明细会同时删除其下所有产出文件，不可恢复。删除前请展开文件列表确认 |
| ⚠️ 警告 | 批量删除时，已锁定的项目会被自动跳过，不会被删除 |
| 📌 注意 | 每页显示 20 条明细，超出自动分页。使用底部分页控件翻页 |
| 📌 注意 | 同一时间只能展开一个项目的文件列表，展开新项目会自动收起之前展开的项目 |
