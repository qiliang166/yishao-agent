## 第八章 系统配置 — 8.1 全局设置

> **所属手册**：后台管理说明（管理员）

全局设置是系统级配置中心，管理员在此管理品牌信息、文件存储路径、安全密码、软件许可证和网站主题风格。

**进入方式**：左侧导航栏 →「⚙ 设置」。页面包含三个标签页：「通用设置」「网站风格」「操作说明」。

---

### 功能概述

**是什么**：系统全局参数的统一管理入口，涵盖品牌标识、默认存储路径、管理员密码保护、许可证激活、UI 主题定制和操作说明书内容编辑。修改后全局生效。

### 界面布局

**在哪里**：左侧导航栏 →「⚙ 设置」。

| 标签页 | 包含功能 |
|------|---------|
| 通用设置 | 品牌信息（LOGO/名称/版本/版权/签名）、文件保存路径、安全设置（管理员手机号/密码保护）、许可证管理、关于信息 |
| 网站风格 | 预设主题列表、主题颜色编辑器（11 个颜色变量） |
| 操作说明 | 章节导航列表（18 个功能区）、Markdown 编辑器 + 实时预览 |

所有标签页共享页面顶部的「全局保存」按钮（操作说明标签页除外，其内容独立保存）。

---

### 一、品牌信息

#### 功能概述

**是什么**：设置系统 LOGO、应用名称、版本号、版权信息和作者签名。这些信息将嵌入导出的文档和 PPT 页脚中。

#### 操作步骤

1. 设置 LOGO：在「LOGO 图标」输入框中输入 emoji 字符（如 ⚡）或图标 URL → 或点击「本地上传」选择图片文件 → 右侧实时预览（28×28px）
2. 设置应用名称：在「应用名称」输入框中输入系统名称
3. 设置版本号：在「版本号」输入框中输入版本（如 1.0.0）
4. 设置版权信息：输入版权声明（如「© 2026 你的站点名称」）
5. 设置签名/作者：输入作者名称
6. 点击「全局保存」使设置生效

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 版权信息和签名将作为页脚嵌入导出的文档和 PPT 中 |
| 💡 技巧 | LOGO 支持三种来源：emoji 字符、图片 URL、本地上传。推荐使用 1:1 正方形图片 |

---

### 二、文件保存路径

#### 功能概述

**是什么**：设置所有项目产出的默认存储根目录。每个项目在此路径下自动创建独立子文件夹。各项目可在 Stage 页面中单独覆盖此路径。

#### 操作步骤

1. 在「默认保存路径」输入框中直接输入路径（如 `D:\YISHAOAGENT\data\output`）
2. 或点击「浏览...」按钮 → 弹出系统文件夹选择器 → 选择目标目录
3. 点击「全局保存」

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 路径格式示例：`D:\YISHAOAGENT\data\output`（Windows）或 `/home/user/output`（Linux） |
| 💡 技巧 | 建议选择空间充足的磁盘分区，课件输出（含图片/音频）可能占用较大空间 |

### 三、安全设置

#### 功能概述

**是什么**：设置管理员手机号（用于忘记密码时验证身份）和系统访问密码。开启密码保护后，登录和敏感操作均需输入密码。

#### 操作步骤

##### 设置管理员手机号

1. 在「管理员手机号」输入框中输入手机号
2. 点击「全局保存」

##### 开启密码保护

1. 勾选「密码保护」复选框
2. 输入新密码 → 在确认密码框中再次输入（至少 4 位）
3. 点击「保存密码」→ 保存成功后自动退出并跳转到首页

##### 关闭密码保护

1. 取消勾选「密码保护」复选框
2. 弹出确认对话框：「确定要关闭密码保护吗？关闭后无需密码即可访问系统。」
3. 点击「确认」→ 密码保护关闭

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| ⚠️ 警告 | 关闭密码保护后，任何人无需密码即可访问系统和修改配置。建议始终保持开启 |
| 📌 注意 | 管理员手机号用于忘记密码时的身份验证，建议设置真实有效的手机号 |
| 💡 技巧 | 密码建议使用 8 位以上，包含字母和数字的组合 |

### 四、许可证管理

#### 功能概述

**是什么**：管理软件的激活状态。一个许可证密钥仅绑定一台机器。激活后显示序列号、产品版本和激活时间。

#### 界面布局

**在哪里**：「通用设置」标签页 →「许可证管理」区域。

| 状态 | 显示内容 |
|------|---------|
| 已激活 | 序列号、产品版本（标准版）、激活码（部分隐藏）、激活时间、「解除激活」按钮 |
| 未激活 | 红色警告横幅「未激活 —— 请输入有效的许可证密钥」+ 激活码输入框 +「激活」按钮 |

#### 操作步骤

##### 激活许可证

1. 在许可证密钥输入框中输入激活码（格式：`YSAG-XXXXX-XXXXX-...`）
2. 点击「激活」或按 Enter 键
3. 等待验证 → 成功显示已激活状态

##### 解除激活

1. 点击「解除激活」→ 弹出确认框
2. 输入管理员密码 → 点击确认
3. 系统进入未激活状态

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 一个许可证密钥仅绑定一台机器。解除激活后系统将进入未激活状态，需重新激活才能正常使用 |
| ⚠️ 警告 | 不要在未备份的情况下解除激活，重新激活可能需要联系管理员获取新密钥 |

### 五、关于信息

#### 功能概述

**是什么**：展示当前系统的应用名称、版本号、版权信息和作者。纯展示区域，不可编辑，内容来源于品牌信息设置。

### 六、网站风格

#### 功能概述

**是什么**：自定义系统 UI 配色方案。支持预设主题一键切换和自定义颜色变量（11 个）。当前使用的主题标注「✓ 使用中」。

#### 界面布局

**在哪里**：「网站风格」标签页。

主题以卡片网格展示，每张卡片包含：

| 元素 | 说明 |
|------|------|
| 4 色预览条 | 主色调 / 背景色 / 卡片色 / 文字色 |
| 主题名称 | 可编辑（默认主题不可修改） |
| 操作按钮 | 「启用」（灰色）或「✓ 使用中」（绿色）+「✏ 编辑」 |

#### 操作步骤

##### 切换主题

1. 点击目标主题卡片的「启用」按钮
2. 全站 UI 立即切换为所选配色

##### 自定义主题颜色

1. 点击任意主题的「✏ 编辑」→ 展开颜色编辑面板
2. 11 个颜色变量以网格布局显示：

| 序号 | 变量名 | 用途 |
|------|--------|------|
| 1 | 主色调 | 导航栏/按钮/强调元素 |
| 2 | 背景色 | 页面背景 |
| 3 | 卡片色 | 卡片/面板背景 |
| 4 | 文字色 | 正文颜色 |
| 5 | 次要文字 | 辅助说明文字 |
| 6 | 边框色 | 分隔线/表格线 |
| 7 | 浅色背景 | 悬停/选中背景 |
| 8 | 成功色 | 已完成/已启用状态 |
| 9 | 警告色 | 警告/删除按钮 |
| 10 | 悬停色 | 鼠标悬停反馈 |
| 11 | 保存按钮 | 保存按钮颜色 |

3. 每个变量提供：取色器 + 十六进制色值输入框
4. 修改后点击「💾 保存修改」

##### 创建新主题

1. 选择一个非默认主题 → 修改名称为新名称 → 编辑颜色
2. 保存后即为新主题（通过复制/修改现有主题实现）

#### 提示与注意事项

| 类型 | 内容 |
|------|------|
| 📌 注意 | 「经典酒红」为系统默认主题，不可修改名称或删除 |
| 💡 技巧 | 修改颜色后实时生效，可边调边看效果 |

### 七、操作说明编辑

#### 功能概述

**是什么**：为 18 个功能区编写和编辑操作说明书内容（即本手册各章节）。支持 Markdown 格式，左侧编辑右侧实时预览。每个章节独立保存。

#### 界面布局

**在哪里**：「操作说明」标签页。

| 区域 | 控件 |
|------|------|
| 左侧章节列表 | 18 个功能区名称按钮，分为「前台操作说明」和「后台管理说明」两组 |
| 中间编辑区 | 章节标题输入框 + Markdown 编辑文本框 |
| 右侧预览区 | 实时渲染的 HTML 预览 |
| 底部按钮 | 「保存当前章节」（每个章节独立保存） |

#### 操作步骤

1. 切换到「操作说明」标签页
2. 在左侧章节列表中选择目标章节（如「Stage 1 — 视频提取」）
3. 在「章节标题」输入框中修改显示标题
4. 在 Markdown 编辑区编写说明内容（支持标题、表格、列表、加粗、emoji 等）
5. 右侧面板实时渲染预览效果
6. 点击「保存当前章节」→ 内容写入数据库 → 前台 ManualPage 和各功能区 ? 按钮立即可见
