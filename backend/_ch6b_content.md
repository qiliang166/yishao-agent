## 第六章 演讲课件 — 6.2 演讲口播

> **所属手册**：前台操作说明（使用者）

演讲课件是五阶段流水线的第四阶段。本页面提供**演讲口播（TTS 语音合成）**方式——将演讲稿文本通过 TTS 引擎合成为自然语音音频。演讲文案生成通过左栏顶部子标签切换。

页面采用**左右双栏布局**：左栏为音色管理与变声控制面板，右栏为文案编辑与语音合成面板。

---

### 功能概述

**是什么**：选择 TTS 引擎和音色 → 输入或导入演讲稿文本 → AI 语音合成为 MP3 音频文件。支持系统预设音色和自定义克隆/设计音色。

**两大核心功能**：
- **语音合成**：将文本转为自然语音（MP3 格式），可调节语速和音量
- **变声定制**：通过录音克隆或文字描述设计，创建专属音色

### 界面布局

**在哪里**：进入项目明细后，点击顶部流水线导航「④ 演讲课件」，左栏子标签选择「演讲口播」。

| 卡片 | 位置 | 控件 |
|------|------|------|
| 🎙 演讲口播 | 左栏 | TTS 提供商选择器、变声模式标签（克隆/设计）、绑定模型选择器、音色选择器、「我的音色」列表（播放/音量/语速/编辑/删除）、「开始克隆」或「开始设计」按钮 |
| 📁 项目保存路径 | 左栏底部 | 路径输入框、📂 打开文件夹、保存按钮 |
| 📝 文案编辑与合成 | 右栏 | 文案来源选择器（文档演讲/分析演讲/综合演讲/白板编辑）、文本编辑区、「语音合成」按钮、历史合成列表（播放/下载/重命名/删除） |

### 操作步骤

#### 语音合成（使用系统音色）

1. **选择 TTS 提供商**：在「TTS 提供商」下拉框中选定语音合成服务商
2. **选择音色**：在音色选择器中点击系统预设音色，点击音色旁的播放按钮可试听
3. **选择文案来源**：在右栏来源选择器中选定文本来源
   - 「文档演讲」/「分析演讲」/「综合演讲」：自动载入 Stage 4a 生成的对应演讲稿
   - 「白板编辑」：手动输入或粘贴文本
4. **编辑文本**（可选）：在文本编辑区修改待合成的文本内容
5. **语音合成**：点击「语音合成」→ 按钮变为「⏳ 合成中...」→ 完成后音频出现在下方合成列表中
6. **播放/下载**：在合成列表中点击「▶」播放音频，点击「⬇」下载 MP3 文件

#### 变声定制 — 克隆模式

1. 在左栏切换到「克隆」标签
2. 选择绑定模型（默认 cosyvoice-v3.5-plus）
3. 点击「选择文件」上传一段音频样本（或点击录音按钮现场录制）
4. 录音流程：点击录音 → 3 秒倒计时 → 开始录制（显示波形可视化）→ 点击停止 → 预览录音 → 点击「开始克隆」
5. 输入音色名称 → 确认 → 等待克隆完成 → 新音色出现在「我的音色」列表中

#### 变声定制 — 设计模式

1. 在左栏切换到「设计」标签
2. 选择绑定模型
3. 在「声音描述」文本框中输入音色描述（如"温柔知性的年轻女性声音，语调自然流畅，适合阅读和讲述"）
4. 在「预览文本」中输入试听文本（如"各位听众朋友们大家好，欢迎使用我的语音合成服务"）
5. 点击「开始设计」→ 输入名称 → 等待生成 → 新音色出现在「我的音色」列表中

#### 管理自定义音色

- **播放试听**：点击音色旁的播放按钮
- **调节参数**：拖动音量滑块（0-100）和语速滑块（0.5-2.0）
- **重命名**：点击编辑图标 → 输入新名称 → 确认
- **删除**：点击删除图标 → 确认后永久删除

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| TTS 提供商 | 语音合成服务商 | 选择已启用的提供商 |
| 音色 | 合成语音的声音特征 | 系统推荐音色或自定义克隆音色 |
| 音量 | 合成音频的输出音量 | 默认 50（范围 0-100） |
| 语速 | 合成语音的播放速度 | 默认 1.0（范围 0.5-2.0） |
| 绑定模型（变声） | 用于音色克隆/设计的 AI 模型 | 默认 cosyvoice-v3.5-plus |

### 提示与注意事项

| 类型 | 内容 |
|------|------|
| ⚠️ 警告 | 录音克隆需要安静环境和清晰语音，建议录制 10-30 秒的自然朗读音频 |
| 📌 注意 | 变声定制（克隆/设计）需要一定的处理时间（通常 1-3 分钟），请耐心等待 |
| 💡 技巧 | 在「全局设置」→「栏目配置」（col7 语音合成）中为每种演讲类型配置角色提示词，可影响语音的情感表达 |
| 💡 技巧 | 先用「演讲文案」（6.1）生成规范的演讲稿，再用「演讲口播」合成语音，效果最佳 |
| 💡 技巧 | 合成列表中可保留多条历史记录，方便对比不同音色或参数的效果 |
| 📌 注意 | 自定义音色与 TTS 提供商绑定，切换提供商后需要重新创建 |
