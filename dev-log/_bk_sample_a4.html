餐饮服务食品安全管理制度

**文件编号**：FSMS-P&G-001

**版本号**：V2.0

**生效日期**：2026年06月01日

**适用范围**：☑中央厨房 ☑连锁门店 ☑网络外卖 ☑集体用餐配送

**编制部门**：食品安全管理部

**编制依据**：《中华人民共和国食品安全法》《餐饮服务食品安全操作规范》《企业落实食品安全主体责任监督管理规定》《网络餐饮服务经营者落实食品安全主体责任监督管理规定》

---

第一章 总则

**第一条** 为保障消费者食品安全，落实企业主体责任，依据《中华人民共和国食品安全法》及其实施条例、《餐饮服务食品安全操作规范》、《企业落实食品安全主体责任监督管理规定》、《网络餐饮服务经营者落实食品安全主体责任监督管理规定》等法律法规及规章，结合本企业多业态、多门店运营特点，制定本制度。

**第二条** 本制度适用于企业内所有餐饮服务相关岗位人员及操作环节，包括但不限于原料采购、运输、验收、贮存、加工制作、分餐配送、餐饮具清洗消毒保洁、餐厨废弃物管理、人员健康管理、食品安全培训考核、风险隐患排查治理、食品安全事故应急处置等。

**第三条** 企业食品安全管理遵循以下根本原则：预防为主、风险管理、全程控制、社会共治。各部门、各岗位应严格落实本制度要求，确保食品加工经营全过程符合法律法规及食品安全标准。

第二章 组织机构与人员职责

**第四条** 企业建立三级食品安全责任体系，明确各层级食品安全职责。

| 角色 | 职责 | 资质要求 |

|------|------|----------|

| **企业主要负责人** | 食品安全第一责任人，对企业食品安全工作全面负责；提供资源保障；任命食品安全总监及食品安全员；组织制定并发布食品安全制度文件；参加月调度会议并作出决策。 | — |

| **食品安全总监**（食品安全管理人员） | 直接负责食品安全管理工作；拟定并推动落实食品安全管理制度；组织开展日管控、周排查、月调度工作；组织从业人员培训考核（≥40小时/年）；管理进货查验及供应商审核档案；配合监管部门监督检查。 | 经监管部门或委托机构培训考核合格，取得电子或纸质证书；企业内部正式任命。 |

| **食品安全员** | 执行每日食品安全检查（日管控）；检查加工制作过程、专间管理、清洗消毒、人员个人卫生等；如实填写检查记录；发现问题立即报告并采取纠正措施。 | 经培训考核合格，专职或兼职。 |

| **采购员** | 负责供应商资质审核、索证索票、进货查验记录；维护合格供应商名录；确保采购的食品原料符合要求。 | 培训合格，熟悉索证索票要求。 |

| **加工制作人员** | 严格执行岗位操作规程（SOP）；遵守专间管理、生熟分开、温控记录等要求；保持个人卫生。 | 持有效健康证明，完成岗前培训。 |

| **清洗消毒人员** | 负责餐饮具及工用具清洗消毒；按配方配制消毒液，监测消毒参数；维护消毒设备；记录消毒操作。 | 培训合格，掌握消毒剂配比及设备操作方法。 |

第三章 过程控制要求

### 第一节 原料采购与验收

**第五条** 采购管理实行供应商准入与动态评价机制。

| 控制项目 | 要求 | 关键记录 |

|----------|------|----------|

| **供应商管理** | 审核供应商营业执照、食品生产经营许可证及相关资质，建立并动态更新《合格供应商名录》。每年至少进行一次综合评价。 | 《供应商审核表》、《合格供应商名录》 |

| **进货查验** | 每批次原料须查验并留存供货方许可证复印件、产品合格证明文件（检验报告或出厂合格证）；查验食品感官性状、生产日期、保质期、贮存条件；冷链食品须测量并记录中心温度（冷藏0~8℃，冷冻≤-18℃或其他标示条件）。 | 《进货查验记录》（电子或纸质，逐批记录） |

| **仓储管理** | 分区分类存放，离墙（≥10厘米）、离地（≥15厘米），先进先出；配备温湿度计，冷藏、冷冻库须有温度显示和超限报警装置。 | 《温湿度监控记录》、《出入库台账》 |

### 第二节 加工制作

**第六条** 加工过程严格遵守《餐饮服务食品安全操作规范》及企业产品标准操作规程。

| 操作环节 | 食品安全要求 | 检查重点 |

|----------|--------------|----------|

| **粗加工** | 动物性、植物性、水产品分开清洗，清洗池专用并有标识；解冻须在冷藏条件下或使用流动水解冻，严禁反复冻融。 | 水池分类使用、解冻方式、交叉污染风险 |

| **切配** | 刀具、砧板实施色标管理（红-肉、蓝-水产、绿-蔬菜等），专间专用工具不得移出。 | 工具颜色标识、生熟分开 |

| **烹制** | 食品中心温度须达到≥70℃；需要再加热的食品，食用前中心温度须≥70℃；油炸食品不得反复使用煎炸油脂。 | 《中心温度记录》、《煎炸油更换记录》 |

| **专间操作** | 冷食类、生食类、裱花蛋糕、备餐等须在专间内操作；专间使用前紫外灯消毒≥30分钟；空气和操作台定期监测；工器具专用，人员进入须二次更衣、洗手消毒、佩戴口罩。 | 《紫外线消毒记录》、温控监控、人员着装规范 |

### 第三节 清洗消毒与保洁

**第七条** 严格执行“除残渣→清洗→消毒→保洁”完整流程。

| 对象 | 消毒方法 | 参数要求 | 检查方法 |

|------|----------|----------|----------|

| **餐饮具** | 热力消毒（煮沸、蒸汽、红外线消毒柜） | 煮沸或蒸汽≥100℃/10分钟；红外线消毒柜≥120℃/15分钟 | 肉眼检查光洁度，定期采用ATP荧光快速检测 |

| **工用具** | 化学消毒（含氯消毒液浸泡） | 有效氯浓度250mg/L，浸泡≥30分钟；使用前用清水冲净 | 含氯试纸测试消毒液浓度 |

| **保洁** | 消毒后自然沥干或烘干，放入洁净、密闭的专用保洁柜，严禁使用毛巾擦干 | 保洁柜保持清洁、封闭 | 现场检查保洁柜内清洁度 |

### 第四节 外卖配送（适用网络餐饮）

**第八条** 从事网络餐饮服务，须严格遵守市场监管总局相关监督管理规定。

| 控制项目 | 要求 |

|----------|------|

| **入网商户资质** | 必须持有合法有效的营业执照和食品经营许可证；须具有与经营规模相适应的实体经营门店；网络店铺名称应与实体店门头名称一致。 |

| **无堂食外卖** | 若为无堂食门店，须在平台店铺主页显著位置标明“无堂食外卖”字样。 |

| **明厨亮灶** | 鼓励实施“互联网+明厨亮灶”，无堂食外卖门店须按行业及平台要求安装并联网明厨亮灶系统，后厨关键点位实时直播。 |

| **打包与封签** | 须在专用操作区或备餐区完成打包，使用外卖封签或一次性包装袋，确保配送过程不可打开。 |

| **配送要求** | 严禁在食品操作区以外场所进行任何形式的加工制作；平台配送须符合温度要求（热食保温≥60℃，冷食冷藏≤8℃）。 |

第四章 风险管控机制

**第九条** 实施“日管控、周排查、月调度”动态风险管理制度。

| 节点 | 责任人 | 工作内容 | 输出记录 |

|------|--------|----------|----------|

| **日管控** | 食品安全员 | 每日至少一次对食品加工全过程、设备设施、人员健康卫生等进行巡查，发现隐患立即纠正并记录。 | 《每日食品安全检查记录》 |

| **周排查** | 食品安全总监 | 每周对日管控数据、不合格项、投诉等进行分析，组织全面排查，评估风险等级，制定整改方案。 | 《周排查治理报告》 |

| **月调度** | 企业负责人 | 每月召开食品安全调度会议，听取总监汇报，总结风险趋势，协调解决重大问题，部署下月重点。 | 《月调度会议纪要》 |

**第十条** 所有记录、报告、纪要须真实、完整、准确，采用电子化管理系统的，时间戳自动生成，不可篡改；采用纸质的，严禁后补、涂改。保存期限自记录生成之日起不少于2年。

第五章 应急管理与事故处置

**第十一条** 制定《食品安全事故应急预案》，内容包括：

1. 事故分级与报告流程（2小时内向属地市场监管、卫健部门报告）；

2. 立即停止生产经营，封存可能导致事故的食品及其原料、工具、设备和现场；

3. 配合调查处理，如实提供相关资料；

4. 制定召回计划，对已售出产品按规定实施召回；

5. 舆情应对与信息发布。

**第十二条** 每年至少组织一次食品安全事故应急演练，检验预案有效性，并形成《应急演练评估报告》。

第六章 监督、考核与持续改进

**第十三条** 建立食品安全内部考核指标体系，包括但不限于：进货查验合格率、专间操作规范率、餐饮具消毒合格率、培训完成率、隐患排查整改率等。

**第十四条** 考核结果与相关部门及人员的绩效、奖惩挂钩。对严格遵守制度、发现重大隐患者给予奖励；对违规操作、瞒报虚报者追究责任并实施处罚。

**第十五条** 食品安全管理部每年结合法律法规更新、监管要求变化、内部审核结果及消费者反馈，对本制度进行评审与修订，确保其持续适宜和有效。

第七章 附则

**第十六条** 本制度由企业食品安全管理部负责解释与修订。

**第十七条** 本制度自2026年06月01日起正式施行，原相关制度同时废止。各门店、部门可根据本制度制定相应实施细则，但不得与本制度相抵触。

第一章 食品安全法规体系构建

### 一、法律法规金字塔

```mermaid

graph TD

A[《中华人民共和国食品安全法》] --> B[《餐饮服务食品安全操作规范》]

B --> C1[《餐饮服务连锁企业落实食品安全主体责任监督管理规定》]

B --> C2[《网络餐饮服务经营者落实食品安全主体责任监督管理规定》]

C2 --> D[外卖平台新规 总局令第123号 2026.6.1]

```

**【内化于心：为什么是这个结构？】**

这个“金字塔”结构体现了从上到下、从原则到细节的管理逻辑。顶端的《食品安全法》确立了“预防为主、风险管理、全程控制、社会共治”的根本大法原则，是所有行为的最高纲领。中间的《操作规范》将法律要求细化为人、机、料、法、环的全流程操作指南。底部的专项规定则精准“点穴”，分别解决了连锁餐饮的“统一性”风险和网络餐饮“虚拟性”带来的信息不对称、影子厨房等新挑战，从而构建了一个严密且动态响应的法规生命体。这不仅是法规堆砌，更是系统论在食品安全治理中的实践。

### 二、核心法规要点速查

| 法规名称 | 核心要求 | 适用范围 | 生效日期 |

|----------|----------|----------|----------|

| 《中华人民共和国食品安全法》 | 确立预防为主、风险管理、全程控制、社会共治原则；明确生产经营者是第一责任人 | 所有餐饮服务提供者 | 2015.10.1 |

| 《餐饮服务食品安全操作规范》 | 场所布局、设施设备、原料采购、加工制作、清洗消毒等全流程操作标准 | 所有餐饮服务提供者 | 2018.10.1 |

| 网络餐饮主体责任规定（总局令第123号） | 平台审核（实名、每六个月核验）、商户资质（实体门店）、信息公示（无堂食标识） | 网络餐饮服务平台及其入网商户 | 2026.6.1 |

> ⚠️ **安全红线**：

> 1. 网络餐饮服务经营者**必须**具有实体经营门店，无实体门店不得入网经营。

> 2. **严禁**委托其他单位或个人进行加工生产，必须在本店操作区内加工。

第二章 食物安全科学基础

### 一、微生物生长条件

理解微生物是战胜微生物的前提。控制它们的生长，不能靠运气，而要靠科学。

- **温度危险区间**： **5℃-60℃为“危险温度带”**。在此区间内，大多数致病菌会以几何级数快速繁殖。单个细菌在适宜环境下，4小时内可繁殖数千个。

- **pH值(酸碱度)**：多数病原菌在中性(pH 6.6-7.5)环境生长最佳。这就是为什么发面、发酵不当易导致微生物问题。

- **水分活度(Aw)**：Aw>0.85 时多数细菌可繁殖。通过干燥、盐渍、糖渍降低Aw，是古老而有效的防腐原理。

### 二、主要致病菌与防控

| 致病菌 | 常见来源 | 危害 | 科学防控原理 |

|--------|----------|------|----------|

| 沙门氏菌 | 禽肉、禽蛋、生乳 | 细菌侵入肠壁，引发肠胃炎,症状为呕吐、腹泻、发热 | **热致死原理**：充分加热至中心温度≥70℃可灭活。鸡蛋必须清洗表面，防止外壳携带菌污染内容物。 |

| 金黄色葡萄球菌 | 人员皮肤伤口、鼻腔、咽喉 | 细菌在食物中繁殖后产生耐热肠毒素，引发剧烈呕吐 | **毒素防控原理**：肠毒素耐高温，100℃加热30分钟也无法破坏。**关键在于源头预防**，有化脓性伤口人员绝对禁止接触即食食品。 |

| 副溶血性弧菌 | 近海海产品(鱼、虾、贝) | 侵入肠壁，引起剧烈腹痛、血水样便 | **渗透压与控制原理**：该菌嗜盐，对淡水敏感。用淡水充分冲洗海产品可降低风险。同时，它不耐热，烹煮至中心温度≥70℃即可杀死。 |

第三章 全流程关键控制点（HACCP应用）

### 一、流程与CCP识别

我们用危害分析与关键控制点（HACCP）体系来精准识别流程中的“命门”。

```mermaid

flowchart LR

A[原料验收] -->|CCP1:索证与温度检测| B[贮存]

B --> C[粗加工解冻]

C --> D[烹制] -->|CCP2:中心温度≥70℃| E[冷却]

E -->|CCP3:2h内从60℃降至5℃| F[再加热/备餐] -->|CCP4:再加热温度≥70℃| G[出餐/配送]

```

### 二、关键控制点操作卡

**CCP1：原料验收 —— 第一道防火墙**

| 控制项目 | 关键限值 | 监控方法 | 纠偏措施 | 记录 |

|----------|----------|----------|----------|------|

| 冷藏原料表面温度 | ≤8℃ | 使用经校准的红外线或探针温度计，测量表面及内部温度 | 拒收，记录在案，并通知供应商 | 《进货查验记录表》 |

> ⚠️ **安全红线**：不得采购来源不明、无产品合格证明文件、无随货票据的食品原料。采购进口冷链食品，必须查验并留存“四证”（报关单、检疫证明、核酸检测报告、消毒证明）。

**CCP2：烹制 —— 热杀灭的最后机会**

| 控制项目 | 关键限值 | 监控方法 | 纠偏措施 |

|----------|----------|----------|----------|

| 畜禽肉、水产中心温度 | ≥74℃ | 针式温度计插入最厚部位中心，持续15秒以上读数 | 回炉继续加热至达标；若已售出，从顾客处立即召回。 |

> ⚠️ **安全红线**：⚠️热食类食品加工中心温度必须超过70℃，尤其是油炸食品，不能仅凭表面颜色判断成熟度，必须确保内部温度达标。反复油炸的应用应严格控制油温和时间，防止产生有害物质。

**CCP3：冷却 —— 穿越危险区的极速穿越**

| 控制项目 | 关键限值 | 监控方法 | 纠偏措施 |

|----------|----------|----------|----------|

| 烹后冷却时间 | **2小时内**将食品中心温度从60℃降至5℃ | 计时器+探针温度计，每30分钟监测并记录一次中心温度 | 采用速冷柜、冰水浴、分装小份等物理方式加速冷却；若超时未达标，应废弃处理。 |

第四章 多业态特别管理要求

### 一、网络外卖专项管理 —— 打破“信息黑箱”

**科学原理：信息不对称理论**

消费者无法看到加工过程，只能信任平台和商户。我们须通过规则和技术，强制实现信息透明。

1. **资质穿透性公示**：

* **要求**：网店名称必须与实体店营业执照名称、门头招牌保持一致。无堂食的外卖商户，必须在店铺主页显著位置标示“无堂食外卖”字样。

* **原理**：消除“文字游戏”，确保消费者对经营模式有最基础的知情权，也是对商户诚信经营的基本约束。

* [建议补充：官方“食安地图”APP中可查验资质真伪，生成动态防伪码]

2. **包装封签与温度防护**：

* **要求**：使用一次性“**食安封签**”，确保“一餐一签、拆后即毁”。配送须使用符合储存温度的保温箱。

* **原理**：封签是防物理开启的“法律封印”，是区分商户与骑手责任、保障“最后一公里”安全的物证。

3. **平台定期核验与抽查**：

* **要求**：平台对入网商户实名登记，并**每六个月**至少进行一次信息比对核验与实地核查。

* [建议补充：**明确对高风险商户（如无堂食、未实施明厨亮灶）的重点抽查频次（如每月一次）和标准化检查清单**，避免平台裁量权过大。]

> ⚠️ **安全红线**：平台发现商户资质不符或存在重大食品安全隐患，必须立即下线，并向所在地监管部门报告，不得瞒而不报。

### 二、连锁企业总部管理

* **统一标准**：总部须制定统一的产品配方、采购标准和操作SOP，并发布至所有门店。

* **统一培训**：确保所有门店的食品安全管理人员和关键岗位员工接受标准化培训考核，每人每年**不少于40小时**。

[建议补充：**其中应明确线下实操或考核不少于8小时，采用“学时+考核通过”双条件，由监管部门颁发电子合格证书。**]

* **统一供应链审查**：建立统一的合格供应商名录，对核心原料供应商进行定期审计。

* **定期审核与突击检查**：总部品控部门需对各门店定期进行体系审核与“飞行检查”，检查结果与门店绩效考核挂钩。

第五章 动态风控：日管控、周排查、月调度

**管理原理：PDCA循环**

这个制度是戴明环（计划-执行-检查-改进）在食品安全管理中的具体化身。不是增加负担，而是为你的风险防范系统装上了持续的引擎。

### 一、日管控记录表模板（执行—D）

| 检查项 | 是否合规 | 异常描述 | 处理措施 | 检查人 |

|--------|----------|----------|----------|--------|

| 从业人员晨检(无发热、外伤) | ☑/☒ | | | |

| 进货原料温度（冷藏≤8℃） | ☑/☒ | | | |

| 烹饪中心温度（≥70℃） | ☑/☒ | | | |

| 专间紫外线消毒时间（≥30min） | ☑/☒ | | | |

### 二、周排查报告要点（检查—C）

* **任务**：食品安全员汇总本周日管控数据，分析**重复发生**的隐患（如：连续两天消毒记录缺失）。

* **目的**：进行原因分析，是员工意识问题、设备故障，还是SOP不合理？并验证上周提出纠正措施的有效性。

### 三、月调度会议（改进—A）

* **主持人**：企业主要负责人（总经理/店长），必须亲自参与听取汇报、调度资源。

* **核心议程**：

1. 汇报本月重大风险（如：顾客投诉异物、监管部门警告）。

2. 分析趋势数据（如：哪种原料退货率最高？）。

3. 决定资源配置（如：下个月增加专间消毒的投入，申请一笔设备维修费）。

* **输出**：《月调度会议纪要》，各方签字后存档。

> ⚠️ **安全红线**：日管控、周排查、月调度的所有台账记录，必须**真实、完整**，以纸质或电子形式保存**不少于2年**。严禁为保证记录完美而过后补签、造假，这是刑事追责的严重渎职行为！

第七章 案例警示与反思

**【案例一：亚硝酸盐的“致命盐”】**

* **事件回顾**：某建筑工地食堂为图便宜与色泽，将工业用亚硝酸盐误作食盐用于烹饪，导致56名工人集体中毒，嘴唇发紫（紫绀），其中1人因呼吸衰竭死亡。

* **违反规定**：《餐饮服务食品安全操作规范》明确规定，**亚硝酸盐（钠、钾）等非食用物质严禁在餐饮环节采购、贮存和使用**。

* **科学警示**：亚硝酸盐具有强氧化性，能将血红蛋白中的二价铁氧化为三价铁，使其失去携氧能力，导致组织缺氧。这是剧毒，不是一般的防腐剂或调色剂。

* **教训**：对化学品的管理必须做到“专库、专人、专账”。严禁使用无标签、来源不明的白色粉末或结晶体。

**【案例二：外卖“影子厨房”的覆灭】**

* **事件回顾**：某外卖平台上一家月销数千单的“脏脏包”网红店，被曝光其实际地址为居民楼一楼，无营业执照，无食品经营许可证，加工环境污水横流，老鼠乱窜。

* **违反规定**：该商户违反“网络餐饮必须有实体门店”的规定。平台未尽到入网审核和定期核验义务。

* **处罚结果**：该黑作坊被依法取缔关闭。外卖平台因未尽到审查核验义务，被市场监管部门处以顶格罚款，并对相关区域负责人进行约谈。根据2026年6月1日施行的新规，平台将承担更严格的连带责任和信用惩戒。

* **教训**：线上的光鲜不能替代线下的合规。平台必须对“证照不符”“幽灵厨房”负有不可推卸的巡查责任。

第八章 总结与考核

### 学习要点回顾（内化于心）

* **法规是底线**：记住，安全不是成本，是不可触的红线。《食品安全法》与第123号令，既是紧箍咒，更是护身符。

* **温度是生命线**：记住四个核心温度——**5℃、60℃、70℃、8℃**。掌控了温度，就扼住了微生物的喉咙。

* **记录是生命线**：“日管控、周排查、月调度”台账是你履职尽责、免责的证据。真记录，记实事，保存好。

* **信息透明是趋势**：无堂食外卖、平台核验、新技术赋能，正在打破所有灰色地带，最终实现“社会共治”。
